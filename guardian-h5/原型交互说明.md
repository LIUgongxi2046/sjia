# 监护人 H5 原型交互说明

日期：2026-09-28。依据：PRD V1.5.0、页面流程文档，以及用户明确的拍照识别、预警优先、交互简单快捷和功能入口集中要求。采用 iOS Native Style。能力为 `PROTOTYPE` 与 `DESIGN`；使用当前真实的未登录、未接入资料和预警服务未启用状态。

## 1. 页面与布局

主导航为首页、记录、我的。首页负责预警与资料添加；记录负责查阅、摘要及草稿；我的负责账号、患儿管理及资料使用说明。患儿切换入口位于首页结果卡片，登记和查阅页面只显示资料归属，账号、登录、说明及错误页面不显示患儿区域。预警与登记归属首页，摘要与草稿归属记录，关联与登录归属我的，进入子页面时对应导航保持选中。

拍照任务采用照片与确认保存两个页面状态，短任务在同页完成。登记页面提供一个主要保存操作及实际保存状态；草稿自动保存与中断恢复按 PRD 执行，当前服务未接入。通用来源、核对、排序与隐私规则集中于资料使用说明；字段附近保留当前任务所需的提示。数值与原单位相邻，各类时间独立呈现，底部导航避让安全区域。

| 屏幕 | 页面内容与可操作部分 | 当前状态及依赖 |
| --- | --- | --- |
| S01 登录 | 单一账号服务状态及登录操作，访问说明按需展开 | 身份方式等待 D02；不显示未经确认的认证方式 |
| S02 关联列表 | 当前访问状态、申请入口、关联状态及多人权限说明 | 没有登录身份，不读取关联或患儿清单 |
| S02 关联申请 | 同页展示申请状态及按钮；已知病情与核验说明按需展开 | 证明种类及身份流程等待 D02；不收集证明 |
| S02 关联详情 | 关联信息、核验时间、有效范围、本人各项权限 | 所有资源字段标记未读取或未核验 |
| S03 首页 | 预警结果及患儿入口、拍照资料、体温与治疗快捷入口 | 结果位于首位，拍照入口在常用手机首屏可见；服务未启用时不显示风险等级 |
| S04 体温与症状 | 原始体温、单位、测量方式、测量时间、观察项目、三种状态、发生时间、说明 | 单位不预选；观察状态为无法确定；具体项目清单等待 D03 |

| S06 治疗资料 | 添加资料 → 确认保存；原药名与使用状态直接展示，说明、起止时间与出处按需展开 | 优先拍摄处方或治疗记录；状态不默认持续使用，不提供用药建议 |
| S07 记录 | 摘要与草稿入口；类别、项目名称、来源、核对状态、日期范围与清除筛选 | 查看条件可操作，URL 保留非病例筛选条件；资料尚未读取 |
| S08 记录详情 | 原始内容、来源与状态、时间与版本三个内容分组；更正、历史、历次结果操作区 | 分组可以切换；资源字段尚未读取，对应业务操作不可用 |
| S09 历次检验 | 项目、原单位、方法、比较条件说明 | 无获准结果，不能产生方向或趋势；保留不可比较原因设计 |
| S10 更正 | 按体温症状、检验报告、治疗资料查看字段结构；更正原因、版本及资料出处 | 原记录和权限未取得，不能编辑；实际记录类型由服务确定，结构切换不改变记录 |
| S10 历史 | 版本、时间、原因及核对变化的只读结构 | 无获准历史，不生成版本条目 |
| S11 预警 | 直接呈现结果及可用操作，依据与服务状态按需展开 | 未启用状态不输出临床结论或事件 |
| S11 预警详情 | 结果与依据、有效性、本人阅读状态、联系区 | 服务未启用，不记录阅读，不发起联系 |
| S12 摘要生成 | 当前患儿、日期范围、内容目录及就诊查看说明 | 日期可选并即时校验；没有可见记录与服务，不能生成 |
| S12 摘要详情 | 患儿、范围、生成时间、有效性、版本和原始资料目录 | 资源字段尚未读取；不能重新生成或导出 |
| S13 我的 | 一个账号区域、患儿管理与资料使用说明 | 当前账号区域提供登录入口；登录后才显示退出操作 |
| S13 资料使用说明 | 访问范围、来源、草稿与退出、保存与删除、联系状态 | 内容可展开；删除及保存期限等待 D09 |
| S14 草稿 | 从记录页面进入，类别筛选、读取状态与恢复说明 | 系统检查身份、权限和版本；当前只调整类别，不生成或持久保存草稿 |
| S15 访问与服务状态 | 无权限、服务不可用、地址无效及对应可用出口 | 独立路由不显示病例内容 |
| S00 原型页面目录 | 23 个业务及状态页面入口、当前能力说明 | 设计查看入口；详情地址中的 unavailable 表示未取得资源 |

目录路径为 `/prototype`，通过独立评审地址访问。页面目录只组织设计查看，不进入家庭业务导航，不建立病例标识或业务记录。

## 2. 表单规则

### 2.0 家庭任务指引

| 任务 | 默认操作 | 按需查看或补充 |
| --- | --- | --- |
| 检验报告 | 添加照片 → 确认并保存 | 报告来源与时间、逐项核对检验内容 |
| 体温症状 | 同页填写体温与时间，保存本次记录 | 测量方式、症状及其他观察 |
| 治疗资料 | 添加资料 → 确认并保存 | 使用时间、补充说明与资料出处 |
| 患儿关联 | 同页查看申请状态并申请 | 已知病情与核验说明 |
| 记录更正 | 同页填写更正内容并保存 | 原记录、版本与保留规则 |
| 就医摘要 | 同页选择日期并生成 | 内容目录与就诊说明 |
| 预警查看 | 直接查看结果及下一步操作 | 评估依据与服务状态 |

照片页面提供“预览确认页面”查看受限的确认结构；确认页提供保存按钮与“返回照片”。切换时焦点进入当前标题，隐藏页面状态保留组件内容；刷新回到照片页面，不表示上传或保存已经完成。实际服务接入后，上传和识别在同一任务内反馈进度，成功后进入确认页面；优先呈现需要用户处理的项目，完整内容仍可展开核对。短任务无需经过说明页面，主操作与输入位于同页。

内部系统负责识别、提取、来源关联、权限、单位和版本检查。界面根据实际结果指出需要确认或补充的内容，不自动补全未知值，不授予临床核对资格。未满足前置条件时不能保存，用户展开或浏览页面不改变业务状态。

照片流程由用户主动选择拍照或相册。拍照声明后置相机，相册支持多选；当前控件禁用。PhotoReview 提供照片页序、原图展开、重拍、替换及移除确认组件；操作通过回调连接获准文件服务。没有照片时不生成图片或页数。格式限制、上传状态和权限检查需要文件服务及参数。

识别内容必须关联照片与原文位置，无法识别或待确认字段独立说明；本人可以对照原文修正，保留原始识别及修改依据。RecognitionSourceView 按实际照片、页码、原文及位置显示核对区域，位置超出照片范围时立即报错。数值、比较符、单位和日期分别确认，识别完成与本人确认均不授予临床核对资格。当前照片和 OCR 适配尚未接入，页面展示无结果说明；成功、失败及部分识别的业务验证为 NOT_RUN。

### 2.1 共享字段

每个字段有独立可访问标签，说明与字段关联。数值使用十进制键盘提示，保留字符串精度；当前未登录时控件保持禁用且没有默认数值。未知单位不能用预选单位补充。DictionaryField 提供按名称或别名检索、选择和保留原文的组件；选择时携带获准字典版本，不自动换算数值。观察项目、检验项目、报告单位均有入口；当前字典未接入，搜索不可用，原始字段仍完整保留。

时间精度可切换“无法确定”“仅知道日期”“知道日期与时间”。后两种分别展示日期或日期时间字段，并显示时区确认入口；切换精度不填充当前时间。时区属于待确认资料，不能通过浏览器时区自动解释原记录。当前所有病例时间字段保持禁用。

正式接入时，未知时间与日期精度分别提交，采样、出具、发生及系统登记时间保持独立。缺少来源、原单位或项目必需信息时，按 PRD 标记需补正；不能把缺项变为零或未观察到。

### 2.2 报告项目

增加按钮只增加当前页面的空白字段组，至少保留一个字段组。多个字段组显示各自移除操作，移除后将焦点返回增加按钮，状态文字说明已经改变的空白结构。项目使用独立标识，移除中间项目不会转移其他项目的控件状态。

当前病例字段禁止输入，因此移除不会删除病例内容。真实编辑开放后，已有输入的项目移除必须提供确认，取消后保留内容及焦点。正式记录成功保存后，才能进入时间轴和详情。

每条检验项目保存原名称、原始数值、限定符、原始单位、方法和参考区间。没有独立采样时间时使用已确认的报告采样依据，原报告提供项目独立时间时单独保存。单位映射、报告附件与来源接入等待对应批准配置。

### 2.3 治疗资料

实际使用状态初始为无法确定。用于查看字段结构的选择不会修改该状态。“已结束”和“无法确定”均展示独立的结束时间；持续使用显示开始时间。切换展示方式保留已经选择的时间精度，不填充日期，也不更改实际状态。专业治疗分类不能由家庭表单写入。

## 3. 查看条件与页面状态

记录类别、项目名称、资料来源、核对状态和日期范围组成筛选条件。项目条件用于全部或检验报告类别，其他类别暂不使用该条件，切换回来保留名称。日期范围在结束时间早于开始时间时立即显示关联错误；修改后错误消失。修改条件保持当前控件焦点与浏览位置。URL 只保存普通查看条件，不保存姓名、患儿临床内容或认证凭据。返回与刷新恢复这些条件；清除操作恢复全部类别、全部来源、全部核对状态、空项目与空日期。

在当前身份状态下，调整筛选只改变条件说明，不显示匹配数量，不把没有取得资料描述为真实空记录。摘要范围同样提供日期校验，但不生成结果。摘要日期为空时不预填患儿记录时间。

详情分组切换仅更换内容区域。来源与核对状态分别展示，当前未读取字段不默认标记为未核对。详情中的更正、历史和历次结果必须绑定真实记录与当前权限后才可以操作；页面目录允许查看这些受限页面的结构。

ContextLink 记录当前页面、查询条件与浏览位置，页面返回通过原导航记录恢复上下文。摘要与草稿返回原筛选条件；直接访问页面使用明确的父级地址。原记录、摘要依据和预警依据的真实链接接入时复用该组件，原记录操作目前仍受权限限制。

## 4. 服务状态与恢复规格

下表属于必须保留的 `DESIGN`。没有对应服务和获准资料时，不通过随机数据、计时器或替代接口触发成功状态。

SaveActions 提供单一主要操作的状态组件：可提交、处理中、结果待确认、查询中、失败重试、版本冲突和保存成功。状态由真实请求控制；结果待确认仅提供查询，查询中与保存中禁用重复操作。草稿文字单独显示未保存、保存中、失败或服务确认时间。当前表单使用 unavailable 与 unsaved，不触发服务状态转换。自动草稿、离页保护、恢复和请求状态查询仍需要服务适配及业务验证。

| 状态 | 适用页面 | 内容与可执行操作 | 完成判据 |
| --- | --- | --- | --- |
| 正在读取 | 全部资源页面 | 在实际请求期间展示无数值加载结构及读取文字，保留全局导航 | 真实响应决定内容、空数据或错误 |
| 真实空数据 | 关联、记录、草稿、摘要 | 成功响应为空后显示准确空态；按权限提供下一步入口 | 记录成功空响应与当前授权 |
| 筛选无结果 | 记录 | 保留筛选条件，提供清除筛选，不等同整个患儿没有记录 | 同一权限下取得有效筛选响应 |
| 部分资料 | 登记、详情、历次结果、摘要 | 展示原值及各项缺失原因；补正只修改获准范围 | 重新读取原值、来源、时间与补正状态 |
| 读取失败 | 全部资源页面 | 显示实际失败说明和用户主动重新请求入口，不转换为空结果 | 新请求经过权限检查，成功后更新页面 |
| 表单校验失败 | 登记、更正 | 字段旁显示具体错误，顶部提供错误列表并聚焦首个错误字段 | 错误纠正后恢复核对步骤 |
| 尚未保存 | 编辑页面 | 持续显示未保存状态；离开提示继续编辑、保存草稿后离开、放弃编辑 | 只有服务端确认才能显示保存时间 |
| 保存草稿中 | 登记、更正 | 串行保存，校验草稿版本，旧响应不能覆盖新输入 | 重新读取相同账号、患儿与版本的草稿 |
| 草稿恢复 | 草稿、登记、更正 | 核验本人、关联、字段配置及原版本，用户选择恢复或放弃 | 合法草稿恢复到对应字段，过期或已提交资料拒绝恢复 |
| 提交核对 | 登记、更正 | 展示患儿、原值、单位、时间、来源与需补项；更正必须有原因 | 用户确认后发出唯一逻辑提交 |
| 处理中 | 登记、更正、摘要 | 阻止重复操作，不显示完成内容 | 当前请求得到明确结果 |
| 保存结果待确认 | 登记、更正 | 按原 request_id 查询，未知期间禁止新建提交 | 确认成功显示真实记录；确认未提交后才允许重试 |
| 保存成功 | 登记、更正 | 显示服务端确认的记录版本、来源与核对状态，进入真实详情 | 重新读取与提交内容一致，草稿不重复生成记录 |
| 版本冲突 | 更正、草稿恢复 | 展示当前版本已变化，重新读取并要求核对输入 | 仅提交满足 expected_version 的请求 |
| 摘要失效 | 摘要及首页入口 | 明确需要重新生成，停止作为当前有效内容展示 | 当前权限与记录版本下生成并重新读取 |
| 会话失效或关联撤销 | 全部资源页面 | 清除受限内容，进入登录或关联状态页 | 前台恢复、历史返回及新请求重新检查权限 |
| 临床提示未启用 | 首页、提示、提示详情 | 说明功能未启用，无健康结论、提示事件或联系按钮 | 当前原型已呈现此状态 |
| 失效提示或联系信息 | 提示详情、摘要 | 停止展示受影响内容，不自动拨号或记录诊疗完成 | 当前接收、内容、事件及联系版本验证有效 |

离页确认采用 antd-mobile 的可访问弹层；关闭后恢复发起控件焦点。当前没有病例输入，因此不制造离页数据丢失警告。表单数据不得进入 localStorage、sessionStorage、URL、普通日志或离线队列。

### 4.1 服务连接点与恢复交互

以下输入必须由真实服务提供，不在前端预设服务地址、获准项目或病例结果。

| 连接点 | 必需输入及核验 | 页面行为 |
| --- | --- | --- |
| 身份与患儿 | 当前账号、患儿关联、读取及写入权限、会话有效期 | 满足条件才开放输入；每次上传、保存、恢复和返回资料页重新核验 |
| 照片整理 | 已获准照片 id、临时读取地址、页序、文件限制、操作权限 | PhotoReview 的移动、替换和移除由服务确认；处理中禁用重复操作；失败保留原照片组 |
| 照片替换 | 新照片版本及受影响的识别字段 | 新照片成功保存后更新照片组；原识别字段标记待确认，不能沿用已确认标记 |
| OCR 核对 | 照片版本、识别任务标识、逐字段原文、页码、区域、提取值及待确认原因 | 优先呈现待确认项；点击原文展开同页照片；识别失败保留照片并提供重新识别，已确认内容不被新结果直接覆盖 |
| 获准字典 | 版本、项目 id、名称、别名及当前可选范围 | DictionaryField 返回 id 和版本；无结果允许保持原文；无获准映射不换算或归类 |
| 更正编辑 | 实际记录类型、当前版本、原字段、可编辑字段及来源 | 仅呈现对应字段；临床内容不可直接编辑；提交携带 expected_version 与更正原因 |
| 正式保存 | request_id、输入版本、实际请求结果、记录地址及确认时间 | SaveActions 的 submitting 禁用提交；响应未知进入 uncertain 并查询原请求；确认未提交才允许 failed 重试；saved 后进入真实记录 |
| 自动草稿 | 本人、患儿、表单类型、草稿 id、版本、字段配置及保存时间 | 失焦和每 10 秒检查变更并串行请求；收到服务确认才更新草稿时间；失败保持当前输入并提示未保存 |
| 恢复草稿 | 有效草稿内容、当前权限、字段配置、原记录版本、提交状态 | 一个确认区域提供“继续编辑”和“放弃草稿”；恢复成功进入原表单；更正版本冲突先显示变化并重新核对 |
| 离开编辑 | 页面确有未确认保存内容，且用户发起离开 | 弹层提供“继续编辑”“保存草稿后离开”“放弃编辑”；保存失败保持当前页面；放弃操作确认后清除页面输入 |
| 版本冲突 | 最新记录版本与获准内容 | 保留当前输入，逐字段查看最新内容；用户确认后使用新版本提交；不自动合并 |

身份过期或关联撤销时清除受限页面内容，重新认证的同一账号只能恢复仍然有效的服务端草稿。页面关闭、刷新及系统终止不能保证未确认内容已经保存。草稿恢复、离页保护及上述服务适配的运行状态为 NOT_RUN，实际接口和获准资料是继续验证所需输入。

## 6. 交付和检查

源码位于 `src/features/`，共享字段与分组组件位于 `src/components/ClinicalUI.tsx`，日期范围位于 `src/components/DateRange.tsx`，页面样式位于 `src/styles/forms.css`。全部页面复用真实安装的 React、React Router、antd-mobile 和 Lucide 依赖。

浏览器检查脚本为 `scripts/check-browser.mjs`，检查实际本地页面，不拦截请求、不生成病例、不使用截图。检查报告在 `.artifacts/browser-check.json`，包含运行时间、浏览器版本、检查结果、源码与产物 SHA-256。手机真机、真实账号业务、服务端权限与临床验收仍为 `NOT_RUN`。视觉检查遵守用户限制，保持 `NOT_RUN`。

尚需提供认证与关联服务、获准字段和单位字典、资料及草稿接口、版本机制、摘要服务、批准内容与真实授权资料，才能执行相应成功、拒绝及中断恢复验收。完整原型页面与设计规格不替代这些业务证据。
