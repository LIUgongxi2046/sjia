| guardian-h5/src/features/support/NotificationPage.tsx | UI2-39 | 保留原设计过程及状态，连接真实目录、记录、尝试和回执；支持原请求、后台恢复、重读、继续提交、取消与更正 |
| guardian-h5/src/features/alerts/useNotificationDelivery.ts、UI2AlertsPage.tsx | 家庭提示详情 | 显示文字与站内消息准确版本一致且浏览器可见以后确认接收；本人阅读单独保存；后台与权限变化清除当前私密状态 |

原生受理证明来自同一事务保存的实际消息。送达证明来自本人浏览器获得并提交的准确签名票据。read_at 只由本人打开当前有效提示保存，管理读取不修改阅读时间。

当前资格不足、事件失效、主体或关系撤销、许可过期、预算不足或秘密不可用时明确拒绝。开始事务与撤权使用共同资源锁；事务中止不会产生受理回执。已保存的受理、送达事实保留，家庭访问继续依据当前权限与发布。

原请求、接收人和患儿 ID 用于刷新恢复；正文与签名票据不在浏览器持久保存。提交结果未知时查询同一请求。取消仅允许尚无 WriteRequest 的明确 pending 意图，取消不能重试；更正后能够开始新的操作。
