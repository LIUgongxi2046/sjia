目录按当前文书版本与完整权限提供医院、就诊、类型、时间、确认原文、项目、来源和核对筛选。未知医院、时间及就诊归属继续可查；保存的确认文本、准确版本、页面顺序及原件引用共同返回。读取原件再次检查权限。查询使用只读 POST 正文，私密筛选不进入 URL 或浏览器持久存储。

分页绑定身份、授权、当前文书、当前资料序号、运行配置及全部筛选；更正、撤权或当前版本变化后旧游标拒绝继续。索引直接查询保存的确认文本，文书更正产生新版本并立即采用当前内容。

`UI2ArchivePage` 接入 `/archives`，保留患儿选择、添加一批资料、就医摘要、按就诊查找、原稿搜索文字、四项就诊分类、筛选、未知资料入口、本人草稿及健康状态提示。医院、日期、文书、项目、来源、核对、就诊及未知资料筛选实际提交接口正文；返回时保留账号及患儿所属的内存条件和滚动位置。刷新从数据库重新查询，后台恢复重新核验身份和当前资料，稳定目录没有持续查询循环。

`DocumentOriginalPage` 使用准确 `document_id` 读取当前文书，即使尚无就诊或记录也能够查看原件。实际原件保存时间、版本、完整用途授权和副本复核分别呈现；片段引用确认文书文本，页面按保存顺序定位，不能从整份确认文本推断具体原图坐标。`ArchiveOriginals` 按需读取 PNG、JPEG、WebP 或 PDF，核验媒体类型及 SHA-256，使用内存 Blob，退出弹层和后台清理内容，读取失败保留准确状态和重读入口。原件请求同时接受原件与 JSON 错误响应，成功内容严格检查媒体类型。

`LocalTimestampField` 通过 Django 的日期转换方法保存无时区当地时间，带时区值在字段处拒绝。时区单独保存；秒级时间保持输入内容，分钟范围覆盖该分钟，秒级结束范围按准确边界筛选，夏令时间重复及不存在时刻拒绝推断。日期、月份和年度文书仍采用已记录区间并保留精度，未知时间需要明确查询条件。
