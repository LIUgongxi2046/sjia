## 当前实现

- assessment/policies.py 使用严格 Pydantic 定义 assessment-rule-2、qualification-policy-2、unit-mapping-2 和 assessment-context-policy-2。静态规则固定 PRD 的完整变量、标准单位、独立前提及明确状态；专业状态的零一编码与 assertion_state 由准确批准定义。人群、治疗背景、临床状态和迟到结果分别绑定批准政策，未知或未满足时采用政策明确规定的行为。配置不接收另外设置的临床系数或阈值。
- configurations/schemas.py 和 configurations/service.py 登记四种格式，并检查变量集合、项目身份、语境、类别、正数单位转换系数、映射范围及重复引用。格式通过继续核查现有批准、来源、实际验证报告和程序摘要。
- assessment/medical_intervals.py 读取实际日期、时区、明确 UTC offset、分钟或秒级时间。日期形成完整时区区间；未知、歧义、时区不足和内容不一致保持明确拒绝。窗口使用准确批准年龄及边界，不修改保存的 MedicalTime。
- assessment/qualified_facts.py 按当前环境、账号、岗位、逐字段范围、准确规则、窗口、专业政策与 runtime 读取保存的事实。current 使用当前版本，replay 排除截止时间之后的资料，并按当时已经保存的更正版本核查。未知可得时间、语境、专业状态及时间来源保留不足原因。
- 来源检查读取实际原件及摘要、原件与字段附件、用途授权、来源版本和取得时间。provenance.py 核查 ArchivePage 的准确 FilePage、原件版本、checksum、文书页面、文书确认与 current／replay 版本；保存实际对象的完整内容摘要。本人候选确认绑定准确 CandidateField、CandidateSet 和原件批次版本；专业证明绑定准确字段、记录版本、用途、核对政策、来源、核对人员及当前岗位和患儿权限。
- 单位输入绑定实际 UnitMapping、准确批准定义、项目、来源、方法和原单位；复算已保存 NormalizedMeasurement 并检查内容与时间。缺少保存对象时，准确批准定义与实际字段全部检查通过后保存 UnitMapping 和当前时间的 NormalizedMeasurement；源资料的历史可得性继续独立检查。Decimal 运算采用批准 runtime 精度，精度超限直接终止。分类保留限定符进行三值判定，MS 需要精确值；批准映射声明 exact_values_only 时继续拒绝限定值。协议中的 Decimal 使用完整十进制表示，数值与精度保持。
- 政策 evidence_refs 需要已批准、当前可读取且允许 clinical_policy 用途的实际 SourceRevision。比较政策绑定准确单位映射或专业政策，不采用客户端提供的数值及时间参数。
- static_inputs.py 按服务器批准概念查询完整候选，逐项检查权限和资格，超过批准 JSON 容量直接终止。保存全部候选摘要、选择身份、排除原因、关系版本和上下文摘要；没有截取部分候选形成完整结果。
- selection.py 检查实际采样关系的当前版本、专业证明、准确依据、作者岗位及两个事实的权限范围。正式更正关系使用 left 旧事实和 right 更正事实，检测循环；相同采样引用保留一个合格观察，冲突与无法确定的区间顺序保留不足。explicit_clinical_selection 缺少准确选择依据时保持不足。跨检验项目时间差使用完整医学区间检查。
- clinical_selection.py 将明确选择接入资格检查、候选采用和完整输入摘要。current 需要准确事实版本、实际原因、获准原始依据及选择人员的 verify_field 岗位和字段权限；关系排除后的候选继续检查，选择无资格事实直接拒绝。选择正文持久保存在 WriteIntent 与 Task，实际 WriteRequest 和 AuditEvent 记录人员、原请求和保存时间。replay 需要引用截止之前完成的 current 任务，并核查原选择、准确配置、正文摘要、回执、审计、TaskAttempt、当时和当前授权；没有引用时保留不足。结果来源页面读取原选择人员、原因、依据及实际保存时间，不能用当前操作补写历史选择。
- static_computation.py 分别检查 sJIA 与发热状态。分类使用 PRD 三值判定表；MS 需要七项资格及明确专业状态，保存准确贡献和未取整的阈值结果。前提未满足、未知及时间背景不足分别保留状态。上述选择与计算代码尚未取得合格资料正向运行证据。
- configuration_proofs.py 固定准确 ConfigVersion、ConfigApproval、ConfigValidation 与实际程序摘要；同时核查截止时点和当前时点。service.py 固定完整候选、上下文政策、来源、观察区间、授权、epochs 和程序摘要，登记 static-assessment-task-2 Task 与 assessment.requested Outbox。dispatcher.py 将该事件发送到独立 assessment 队列，worker.py 接入静态消费者。
- tasks/lease.py 使用独立连接维护实际租约心跳。执行前与采用前重新读取任务、配置及输入，检查租约代数、任务身份、执行期限和完整上下文。上下文变化登记 superseded；超期和执行失败登记实际 TaskAttempt 原因及 ConsumerReceipt，页面不持续查询已终止任务。当前没有获准静态任务用于正向 worker 执行，租约心跳的业务证据保留待验收。
- 采用结果在同一事务保存 Assessment、逐字段 AssessmentInput、实际标准化值、完整来源引用、AssessmentOutput、依赖关系、TaskAttempt 和 ConsumerReceipt。读取时核查任务、实际输出、逐项对象摘要、完整输入数量、字段身份与固定选择引用；当前范围、epochs 或依赖变化阻止输出采用。
- requests/assessments.py 与三个 API v2 评估接口接入准确提交意图、原请求查询和重试。实际保存回执绑定 Task、WriteRequest 与 AuditEvent；创建返回实际 TaskView。读者使用 read_assessment 范围，提交者查询本人请求继续核查 execute_assessment。API v1 评估要求使用 API v2。
- options.py 与两个实际查询接口提供当前获准病例、记录目录和静态创建配置。配置组合绑定准确规则、窗口、专业政策、四项背景政策和单位映射。观察区间使用保存的独立时间版本；current 拒绝当前已经更新的区间，replay 使用截止之前的准确版本。明确选择列表只提供实际候选及获准字段；读取候选不授予计算资格，提交与 worker 采用继续完整复核。获准依据及历史选择来自实际来源与任务，超过 runtime 容量直接拒绝。
- verification/workflow.py 通过 API v2 处理指定字段请求、逐项核对、准确证明读取和撤销。创建范围从实际记录读取获准字段及覆盖相应字段的核对人员；依据需要当前准确政策、批准来源和患儿用途授权。字段原值、类别值、限定符、检测方法、参考区间及报告标记完整保留。提交按准确 FieldVerificationState.version 检查并修改当前状态；请求保存的字段身份由 WriteIntent 正文、WriteRequest 及 AuditEvent 共同核实。撤销清除当前证明并使其依赖失效，各项操作提升 verification_epoch。
- requests/verifications.py 为创建、提交与撤销登记准确正文、目标、原请求身份、权限上下文及有效期限。原请求读取、继续提交与重试使用服务器保存正文和代数；保存回执绑定实际对象与审计，状态未确定时继续查询相同请求。
- VerificationPage 接入 UI2-34 的创建范围、字段与人员选择、当前政策和依据、结论提交、撤销及保存后重读。页面采用实际字段状态版本，未选择时没有核对结论；未知提交能够读取原请求。离开未保存内容时使用既有弹层，隐藏页面清除受控内容，恢复后重新核验会话。VerificationOriginals 读取准确核对对象引用的原件；服务器逐文件核查完整 read_file 范围、用途、批准与当前处置，内容绑定准确 object_version 和 checksum，客户端再次核查内容摘要并在关闭时释放临时地址。
- guardian-h5 的 assessments.ts 实施严格 Schema 校验、任务身份核查、提交、受理任务查询、保存结果读取及原请求恢复；不发送客户端数值。AssessmentPage 保留 UI2-35 的三个页签、四项依据区域、两个资料入口和说明，连接实际分类与 MS 结果、逐项贡献、来源、缺项与失效状态。既有“观察时段与来源”入口接入病例、准确配置、医学时点和保存区间选择；AssessmentSelectionFields 提供实际事实、原因、依据及历史选择。创建前保存原请求身份，刷新和状态未知时读取服务器原正文与回执，按准确代数继续或重试。查询有结束期限；隐藏页面清除受控结果与候选，恢复后核验当前会话。动态变化属于 T50。
