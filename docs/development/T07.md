## 决策与约束

- antd-mobile 的 `--adm-color-primary` 映射 `--color-primary`、`--adm-color-danger` 映射 `--color-error`；Tailwind 只提供布局工具，颜色与材质来自 CSS 变量。
- 视觉比较保持 NOT_RUN（用户禁止视觉操作），本轮只做 DOM/computed style 行为检查。
- `check-browser.mjs` 在第 305 行存在既有失败（记录页「资料来源」筛选默认值为「全部来源」而脚本期望「报告转录」），属 T16 来源筛选范围，非公共组件回归，交由 T16 处理。
