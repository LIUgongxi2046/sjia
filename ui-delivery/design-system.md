# 儿童数字孪生 UI 设计规范

日期：2026-09-30。版本：UI 3.0。能力：DESIGN。输入模式：混合模式。依据为 PRD V1.5.0、页面流程、原型交互说明及用户对登录后内容、预警、语音、导航与全局三维界面的要求。页面 PNG 位于 screens/png/，组件状态位于 states/png/，预警画面位于 alerts/png/。

## 1. 视觉方向与产品表达

采用系统字体、大圆角、三维黏土图标与具有柔和体积感的内容容器。仅首页、记录、我的显示底部导航；20个二级及更深页面保留顶部返回入口。页面顶部使用深蓝色 #173F70 至 #215B92，以左上方光照形成深度，显示当前任务标题和上下文，跟随页面滚动；不常驻 Logo。卡片使用清晰的阅读底色、亮面上缘、环境阴影与稳定的内容层级。品牌名称为 sJIA 守护者联盟，透明 Logo 与名称组成横向品牌组合，出现在登录身份页上部与我的页面管理内容之后。

共享图标由三张透明四乘四图标表组成，共48个绘制位置。主导航、健康任务与资料分类使用 clinical-3d-icons.png；返回、关闭、缩放和调整使用 utility-3d-icons.png；资料状态与辅助操作使用 extended-3d-icons.png。各位置保持与儿童形象一致的圆润轮廓、蓝青与燕麦色板、左上方柔和光照。多个页面共享同一图标组件及素材；操作名称始终保留可访问文字。图标固定色彩不用于表达临床等级，预警继续以警告色、标题、行动说明和状态文字共同区分。

主画板采用已登录的产品样式。设计性质与示例资料说明保留在画稿外的评审区域及本文件中；产品顶部和预警卡片显示面向家长的文字。患儿、监护关系、体温、症状、报告、治疗、历史与摘要共用 preview/design-scenario.js，便于跨页面核对内容。静态内容不构成真实病例或业务服务结果。

首页以患儿形象组织资料入口，预警结果占据正文首位。形象采用穿着完整衣物、比例自然、表情中性的三维插画。使用正面略带侧向的站姿，手臂与身体保持可辨识间距。形象不对应真实患儿照片，不用表情、肤色、呼吸速度或身体光效表达病情。

“数字孪生”在本次设计中的含义为：以儿童形象关联同一患儿的已记录资料，并通过时间选择查看已有状态。当前 PRD 没有生理仿真、传感器实时监测或病情预测能力，因此界面使用“孩子的记录”“查看当时记录”等准确文字。

婴幼儿数字孪生作为交互参考，不改变 PRD 的患儿适用范围。角色年龄、比例与形象版本需要独立配置；没有获准年龄资料时使用通用儿童形象，不能根据疾病推断年龄。婴儿、幼儿与较大儿童的形象规格见资产说明。

## 2. 首页母版

基准视口为 390 × 844 CSS px。页面主体宽 350 px，左右边距各20 px。顶部保留日期、积极健康的标题与预警入口。正文分为当前预警、儿童与三项症状、快捷记录三组。标准内容与底部导航完整呈现在844 px首屏；系统大字体与较长的动态内容允许自然滚动。

独立评审预览保持390 × 844 px设计尺寸，根据浏览器中实际可用区域的宽度和高度等比例显示完整画框。工具栏、画框和页脚共同使用当前窗口高度；侧栏评审说明独立滚动。页面画稿导出保持原始设计尺寸。长页面在画框内部滚动，底部导航与内容滚动区域分别布局。

从上至下依次为深蓝标题区、预警卡、儿童形象与发热皮疹关节炎卡片、三项记录入口。底部导航保留首页、记录、我的。完整记录由底部记录导航进入；检验完整性由报告页承接。

### 2.1 预警卡片

预警设计共 10 种画面，完整定义见 alerts/specifications.md。关注为琥珀色、重要为橙色、紧急为红色；过程为蓝色或蓝灰色，缺项为琥珀色，无当前事件使用青绿色并注明其含义。颜色同时配合图标、文字与主要操作，不能仅靠颜色区分。

设计控制区可以切换情景与触发状态转换。READ 只更新阅读状态，INVALIDATE 使结果失效。正式产品使用服务返回的获准文字和动作，设计配色不定义临床阈值、疾病概率或复查期限。记录时间和评估时间分别展示。

首页标题为“陪伴安安，健康成长”。预警卡直接展示具体症状或变化、一条就医行动、最近体温与时间，并提供详情入口。完整原因、来源、核对状态、联系信息及规则版本由详情承接。设计审批说明保留在评审区域及文档中。红色急症提示使用条件句，不将未发生的症状写成患儿事实。

报告页默认展示异常标记与 sJIA 关注指标，全部指标可以切换查看；7组待补充资料收进展开区域。异常标记保留报告原文，不根据设计数值推断。分类和 MS 资料完整性由对应详情承接。需求覆盖与尚待完成的设计见 requirements-review.md。

## 原始资料与拍照流程

报告和治疗页面采用相同的原图组件。已上传资料在列表、确认页面和详情中显示缩略图，点击后全屏查看；原图按比例显示，支持翻页、放大、缩小、旋转和键盘关闭。缩略图宽度按双列分配，确认区域采用横向滚动，保存原始文件字节。

流程为拍照或相册选择、核对照片、确认内容、保存与查看记录。拍照使用系统相机入口；相册支持多张选择。每份最多10张，单张不超过20 MB，支持 JPEG、PNG、WebP，解码后不超过4000万像素。整理阶段可以调整顺序、确认移除和继续添加。取消或文件验证失败保留已有照片，返回确认时保留输入，未保存离开时提示处理当前内容。

报告结果默认按报告异常标记优先排序，同时保留需求 F03、F04 的 sJIA 关注项目。原始数值与单位同组显示，参考范围沿用报告文字。完整项目通过“全部指标”访问。新增项目由用户依原图填写，不自动产生识别数值；比较符可以随原始数值保留。治疗名称和实际使用状态优先展示，使用时间和资料来源按需展开。

独立预览通过 IndexedDB 保存用户选择的图片与登记内容，并读取保存结果后展示成功。产品页面明确显示“当前设备”；服务器上传、OCR、真实账号授权和跨设备同步尚未接入。项目尚未提供获准原始报告及治疗照片，既有示例记录不附生成的报告图片。

### 2.2 儿童资料区域

区域标题显示当前患儿称呼、性别和年龄，支持进入患儿管理；右侧提供健康档案入口。首页使用 identity/master/toddler-boy-autumn.png，完整形象按 contain 适配。形象选择位于展开后的健康档案中。

首页角色居中显示，下面排列三项症状插画及简洁状态。症状图片与卡片左右边缘保持至少20 px安全距离，与上方儿童展示区、下方状态卡片分别保持8 px间距；图片使用14 px圆角，390 px基准宽度下高度为96 px。健康档案面板提供体温、症状、检验、治疗四类完整入口；资料来源、发生时间、示意部位和核对状态由对应详情展示。

首页儿童展示区随视口宽度调整，390 px基准视口约250 px高，最小232 px，最大300 px。形象容器维持135:164比例，图片继续使用完整的contain适配；三项身体标记保留相对位置与44 px触控范围。

儿童形象提供发热、皮疹、关节炎三个分类标记，并配套三联症状示意插画。标记分别关联头部、前臂及膝部的概念示意，明确注明不代表真实受累位置。症状卡显示记录内容、时间、来源及核对状态。关节不适属于监护人观察；关节炎诊断与活动性需要临床资料确认。症状登记支持主动填写部位，不从自由文字推断身体坐标。

没有登录、没有关联和读取失败分别展示当前原因。授权读取成功后没有记录才显示“暂无记录”。没有取得数据时标签不得显示正常、零次、无症状或已核对。角色素材加载失败显示“形象暂时无法显示”，保留文字入口及重新加载操作。

### 2.3 展开查看与时间选择

“展开查看”打开最大高 88dvh 的底部面板，保留患儿标识、关闭按钮、角色与标签、时间选择、记录列表。面板采用真实标题和可访问对话框语义，关闭后恢复入口焦点。角色区域允许查看正面与背面，使用同一角色的获准素材；未提供背面资产时不展示该控件。

时间选择只包含授权返回的真实事件时间。默认显示“最新记录”，并按类别注明各自记录时间。切换历史时标题明确变为“查看当时记录”；系统根据已确认的时间规则选择记录，未知规则不得默认沿用更早值。不同日期之间不插值、不自动播放、不生成预测时段。

只有一个可用时间点时提供该时间说明，无历史切换。时间未知的记录进入独立“时间待补充”列表，不参加时间刻度。选择历史后，顶部当前预警保持当前含义；历史面板不将历史提示标记为当前有效。

### 2.4 家庭操作

首页快捷记录采用三列按钮：记录症状、上传报告、治疗记录。记录症状使用主操作蓝色，其余使用白色卡片；每项最小高度74 px。资料查看与资料登记使用不同动词，点击已有症状进入详情。

快捷主操作与表单主按钮共用主要操作颜色、渐变、边框和阴影，操作圆角统一为18 px。深色主题从同一组语义变量取得对应颜色。登记页面的语音与照片主按钮继承至少52 px高度；快捷记录继续保留74 px高度。

底部只保留首页、记录、我的。当前导航使用蓝色图标和文字，浅蓝背景只用于选中项。页面目录和设计说明不出现在家庭导航。

## 4. 字体、间距与适配

字体顺序为 -apple-system、BlinkMacSystemFont、SF Pro Text、PingFang SC、Helvetica Neue、sans-serif。页面标题 28/36 px、主要状态 24/32 px、卡片标题 18/26 px、正文及输入 16/24 px、辅助说明 14/21 px、标签 12/18 px。数字使用 tabular-nums，保留原始精度与原单位，长数值允许换行。

间距采用 8 px 主尺度，4 px 用于文字与图标的局部距离；常用 8、16、24、32、40、48 px。卡片内边距 20 px，卡片之间 16 px，字段之间 24 px。圆角：小标签 8 px、输入 14 px、操作 18 px、内容卡片 24 px、展开面板 28 px。

标准内容宽度 320—580 px。320—359 px 使用 16 px 页面边距；360 px 起使用 20 px；较宽屏幕内容居中，主体最大 580 px。儿童资料区域在窄屏改为角色上方、标签下方两列，不压缩文字。200% 字号与低高度横屏改为单列标签，允许纵向滚动。

主栏目底部保留导航实际高度及 env(safe-area-inset-bottom)。二级页面只保留正文底部24 px和安全区，提交按钮位于表单内容之后。顶部返回优先返回实际来源页面并恢复浏览位置；直接打开二级页面时按 navigation.js 定义返回父页面。键盘打开后当前字段、字段错误和提交操作都可滚动到达。弹层只保留一个内部滚动区域。

底部导航在原有透明层上加入向下渐变、浅色边缘和内侧高光；深色模式使用深蓝灰容器。浅色卡片从 #FFFFFF 渐变至 #EFF5FB，深色卡片从 #293B50 渐变至 #172637；体积感由表面亮度差、1px 顶部高光和两层环境阴影构成。正文、数值和医学原始资料保持清晰阅读，背景光只出现在容器外缘与儿童展示区。点击反馈为向下移动1px，减少动态效果设置下取消该位移。

三张图标表均为1254 × 1254 PNG、透明背景，单元采用四乘四裁切。共享组件按位置显示原始图片，16—32 px 的图标使用同一高分辨率源，覆盖常用屏幕像素密度。不得将图标重新上色以暗示病情、将儿童材质添加到原始医疗照片，或用阴影遮挡文字、操作和焦点轮廓。全局材质参数见 tokens.json 的 material3d，页面规则集中在 preview/dimension-theme.css。

## 6. 动效与角色行为

标签状态变化 160 ms，面板展开 240 ms，选择角色视角 240 ms 交叉渐变。禁止角色持续摇摆、呼吸计数、心跳光效和自动旋转，这些表达容易被理解为实时测量。没有病情驱动的哭泣、疲倦或康复表情。

系统启用 prefers-reduced-motion 时取消非必要动画，面板立即切换。图片未取得时不显示形似完成角色的替代图案。欢迎、说明和空数据场景可以使用同一中性角色；保存完成使用文字及标准 Check 图标。错误页面使用标准图标和操作说明。当前产品没有连续学习、奖励和关卡，相关 IP 状态不适用。

模块共享深蓝顶部与清晰的内容分组。登录身份页展示当前已登录账号；我的展示监护关系与管理入口；记录采用时间组织；摘要采用阅读布局。儿童角色用于首页、资料面板和患儿管理，长表单与摘要保留完整阅读空间。

品牌组合使用与现有 Master 同源的 identity/2x/logo-embrace@2x.png，Logo 放在58 × 58 px 的浅色容器中，图形与“sJIA 守护者联盟”并列。登录身份页以品牌组合引入账号内容；我的页面将品牌组合放在管理入口之后、退出操作之前。首页维持预警、儿童与快捷记录三组内容，其他任务页面沿用当前任务标题，不增加常驻品牌区域。Logo 保持品牌原有的平面几何形态，容器沿用三维页面材质；品牌图形不承载病情等级。

## 7. 数据表达与绘图

体温以原始数值、原单位、测量时间和测量方式显示；症状显示实际记录的观察到、未观察到或无法确定；检验显示原名称、原值、比较符、原单位及采样时间；治疗显示原药名、原始使用状态、时间及来源。

曲线只在存在获准且可比较的记录时绘制。横轴使用真实采样或测量时间；未知时间独立列示。触控数据点展开文字明细，同步保留完整文字列表。限定值不画成精确数值点。单位、方法或同时间结果冲突时暂停连接曲线，显示原因。

统计图不使用正常范围色带、风险分数、综合健康分、器官热图、疾病进度或自动病情解释。资料核对状态不能决定角色颜色。头像年龄和姿态与资料状态分别管理。

## 8. 全页面应用与开发标注

23 个业务及状态页面逐项规格见 screens/page-specifications.md，独立评审目录不计入业务分母。首页新增一个儿童展开面板与四类资料面板，属于交互补充，不新增底部导航。全部状态规格见 states/state-specifications.md。

设计预览继续使用已有 React 与系统字体，统一图标组件从三张 PNG 图标表读取三维素材。业务数据通过现有后续接口设计传入；组件不得自行生成记录、计算风险或写入临床标识。字段在服务端完成权限投影后才参与展示，前端不能仅隐藏不允许的字段。

语义 Token 使用 tokens.json。角色与业务数据分层：角色负责视觉资产，标签负责内容及入口，时间选择负责当前查看范围，预警卡片负责获准提示。每一类内容绑定患儿、来源记录、时间和有效性，切换患儿时共同清除。

设计文件独立于 guardian-h5 应用源码。预览支持页面切换、表单编辑、设计结果反馈、资料面板、记录筛选和预警状态转换。页面使用标注的设计情景，实际服务、资料权限和临床验收另行执行。图稿与检查范围见 ui-audit.md。

症状语音入口使用浏览器语音识别，界面说明声音可能由在线服务处理。只有主动点击后开始，结束后核对文字再加入症状说明；既有说明保持原文。体温、时间与症状字段不自动覆盖。未确认文字与正在进行的语音阻止表单提交；用户可确认加入或主动清空。AI 辅助的优先级、提取确认和服务依赖见 ai-assistance-review.md。
