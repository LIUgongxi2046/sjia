## 当前功能

UI2Frame直接加载原稿样式和Token，使用准确Logo、儿童形象及图标。首页标题采用设计文字“陪伴孩子，健康成长”。标题、返回、三项导航、滚动位置和说明弹层由共享容器维护。支持正式通知记录入口为/support/deliveries。错误代码允许换行；离线读取显示网络状态。表单fieldset保留禁用语义并取消原生边框、边距和最小内容宽度；治疗日期容器允许在原稿网格内缩小。出处确认采用原稿checkbox-row样式。

全部正式页面连接当前功能模块：

| 页面范围 | 当前模块及业务 |
| --- | --- |
| UI2-01—04 | 首页；体温与症状；报告及照片；治疗原药名、使用状态、独立日期、出处及确认 |
| UI2-05—10 | 记录查询、详情、历次检验、更正、历史及准确版本 |
| UI2-11—14 | 预警目录、提示详情、就医摘要范围及摘要详情；结构预览准确标记未生成 |
| UI2-15—21 | 我的、用途说明、登录、患儿管理、关联申请、关联详情及服务端草稿 |
| UI2-22—24 | 权限、服务及页面不存在状态 |
| UI2-25—33 | 档案目录、批次、逐项确认、归组、重复关系、新增内容、观察时段、资料提醒及原始资料 |
| UI2-34—39 | 专业核对、静态与动态评估、配置发布、评价集合、用途副本与处置、通知及回执 |

字段配置按当前身份、有效关联、准确字段、作者范围及当前配置读取。本人记录的字段定义传入author_id，保留own范围；实际对象读取继续核验对应作者。观察、报告、治疗、更正分别保留原值、字符串数值、比较符、单位、方法、医学时间和准确来源。未知时间保持未知，月份不补充日期。

草稿使用服务端保存和准确draft_id、版本、人员、患儿及表单恢复。修改状态使用fast-deep-equal比较字段内容，服务端JSON字段顺序不产生新增修改。断网失败保留当前输入，恢复网络后查询保存状态并由本人重试。草稿不进入时间轴和临床计算。提交与原请求恢复继续采用WriteIntent、request_id、generation及准确回执。

NavigationMemory保存当前会话的返回位置和滚动状态；退出及患儿切换清理内容。详情、版本、原件和摘要核验返回对象与当前范围。原件按本人操作读取private/no-store内容，校验SHA256后建立Blob URL；关闭、后台和权限核验取消读取并释放资源。说明弹层维护焦点范围、Escape及关闭行为。

新增业务的专业规则、模型与保存流程分别见T40—T53主记录；治疗MedicationEvent完整接入继续归属T14。公共界面不增加家庭专业权限。
