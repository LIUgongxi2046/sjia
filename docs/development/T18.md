## 检索与输入依据

读取依据：[PRD 第 8.4、8.14.2 节](../../sJIA合并MAS预警平台PRD.md)、[预警编排 LLD 第 2、3.2 节](../../sJIA合并MAS预警平台预警编排LLD.md)、[node.schema.json](../../alert-design/node.schema.json)。

关键采用结论：

- 2016 分类五条件：铁蛋白必需（>684 ng/mL）与四项（血小板 ≤181、AST >48、甘油三酯 >156、纤维蛋白原 ≤360）。
- 组合：前提满足 + 铁蛋白满足 + 四项至少两项满足 → meets；前提未满足 → not_applicable；前提未知 → insufficient；铁蛋白未满足 → not_meets。
- 五项比较符与阈值形成三值 met/not_met/unknown；未核对、未知单位、时间不可用均为资料不足。

## 决策与约束

- `evaluate_threshold` 用区间语义实现五项比较符与 gt/le 条件的三值判定（met/not_met/unknown）。
- `classify_2016` 按 PRD 8.14.2 判定表自上而下；未核对字段 value 置 None 即 unknown。
- 边界两侧（684/181/48/156/360 及两侧）逐项覆盖；不使用临时病例作为临床通过证据。
