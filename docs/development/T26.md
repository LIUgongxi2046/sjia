## 决策与约束

- 申请 pending→approved；逐对象 pending→retained/deleted/failed/awaiting_provider。
- retained 要求 retention_evidence_ref + recheck_at；deleted 要求 receipt_ref（+ receipt_sha256）。
- 真实数据销毁只在指定范围执行（T29/T33 依据 D09）。
