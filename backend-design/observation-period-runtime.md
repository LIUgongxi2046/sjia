# 本人观察资料的运行可见字段

当前设计为ACCEPTED，范围为FR-19、GRAC-07。依据PRD第8.19.7节、已有observation-period.schema.json及用户2026-10-18委托软件开发与批准的授权。T47和QA20维护实际业务验证；本设计不授予专业核对或采样频率资格。

backend-runtime-1增加可选UUID字段observation_period_visibility_config_id。观察时段读取必须使用该字段准确引用的visibility-1配置，核验当前环境、family_observation用途、clinical_fields为空、启用状态、来源、批准及当前代码验证。缺少引用或范围不符立即返回503与OBSERVATION_PERIOD_VISIBILITY_UNAVAILABLE。其他运行能力无需为此字段配置内容；没有自动继承家庭摘要发布配置的路径。

原有ObservationPeriodVersion保存、本人标签、医学时间、原请求、版本、保留依据、依赖失效及接口结构保持。当前和历史范围中的采样资料每次按当前明确可见字段及真实权限读取，准确snapshot_version继续包含运行版本和可见字段配置。配置本身不增加病例读取权限；读写和原件继续使用现有事务与权限检查。

观察范围保存需要运行版本准确引用唯一、当前有效且已批准的observation类保留策略。读取结果的allowed_actions只在该策略和本人写入权限同时有效时提供observation_period_change；策略尚未具备时返回OBSERVATION_PERIOD_RETENTION_UNAVAILABLE原因，已有获准资料继续可读。实际保存准备仍独立检查准确策略，缺少或存在多个策略时立即返回503，不采用其他资料类别的策略。

没有医学时间、独立采样关系、有效专业核对或获准频率时，分别保留明确不足原因，采样间隔保持未知。上传及可得时间不替代医学时间。临床提示与就医摘要继续执行各自发布和联系资格。

配置迁移通过登记新的运行版本，明确选择已经获准的档案可见字段版本，按当前代码验证并启用。现有保存范围及原请求不改写，历史读取采用当前合法字段范围。实际验收使用已批准原件中的32项真实检验事实，核验未知时间、原值、准确来源、重复读取、撤权及实际页面恢复；完整V47继续需要原任务要求的真实高频与稀疏资料。
