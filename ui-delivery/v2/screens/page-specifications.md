# 页面与流程说明

页面稿统一位于 index.html，使用 `?screen=页面标识` 查看；准确标识、路由、PRD 关联和适用状态见 screen-design-map.csv。源文件为 src/main.jsx、src/styles.css 和 src/catalog.js。

## 家庭首页与录入

home 保留当前提示、儿童资料入口和拍照主操作。observations 在同页处理体温、医学时间、语音流程入口与三值症状；correction 同时呈现必要更正原因。reports 与 therapies 共用原件选择和清单，治疗独立保存实际使用状态。选择的真实文件只在当前页面显示名称，不触发上传和识别。

确认流程进入 confirm，字段逐项包含项目、比较符、原值、单位、医学时间和精度；展开语境及来源，不复制默认共同时间。grouping 表达文书、医院、就诊与原始时间；duplicates 明确相同文件、文书副本、采样引用、独立采样和更正的关系。未知关系保持未知。

## 家庭档案与资料更新

records 提供时间轴、长期档案、观察时段、就医摘要和本人草稿。archive 支持医院、就诊、文书及已确认原文查找；筛选折叠在同页，未知归属可单独查看。batch 按接收、识别归组、本人确认、归档组织进度，页面恢复依赖真实服务端任务；成功页不受失败页重试影响。

delta 将新增事实、重复资料和待核对内容分组，显示明确比较基准。period 呈现时段、自报标签、采样时间及实际间隔。analyte 保留历次值和不可比较原因，没有真实采样时不绘制虚构曲线。

detail 的原始内容、来源状态、时间版本分别查看；history 与 version 保留只读历史和当前权限。original 展示原件、页面、医院、用途副本及复核状态。drafts 只描述本人服务端已保存的草稿，没有真实草稿时显示空内容。

## 提示与就医沟通

alerts 显示当前有效性与历史入口；alert-detail 展示批准文字的内容位置、资料、核对、时间与联系。缺少批准时保持未启用。关注、重要、紧急等画稿由独立设计控制区切换，不绑定虚构检查结果，不构成临床触发。

summaries 提供日期范围和资料选择；summary-detail 采用适合手机阅读的纸面层次，原始事实、时间、来源共同展示。没有有效输入时不生成摘要；更正和撤权继续影响读取。点击设计操作显示当前未提交或缺少依据，不产生虚假成功。

## 身份、关系与提醒

account 包含登录、患儿管理、资料提醒和使用说明。login 说明实际认证方式需要配置；associations、association-new、association-detail 分别表达列表、申请和权限范围。data-use 按查看范围、外部识别、副本、保存删除、维护联系方式分组展开。

reminders 默认关闭，可在当前设计表单启用、暂停和关闭，设置目标、时间、时区及安静时段。所有操作均不调度真实任务。资料提醒不改变健康状态，也不产生检查安排。

## 受控支持

verify、assessment、publication、dataset、privacy、delivery 六个页面从 PRD 支持职责推导。它们不进入家庭导航，顶部始终显示独立岗位授权要求。

- verify 按指定原件、字段和版本提交一致、需补正或无法确定。
- assessment 分别呈现静态分类、MS 七项资格与动态变化；replay 无家庭发布入口。
- publication 呈现资料资格、规则、独立验证、文字、联系和渠道条件；条件不足禁用启用操作。
- dataset 分别显示文件、页面、患儿、事件和观察区间，不预填收集数量。
- privacy 按目标用途核查原件、副本、自动处理、人工复核及临床字段完整性。
- delivery 分别展示待发送、受理、送达和查看的证据要求，未知结果查询原请求。

## 系统及返回

access、service、missing 分别表达权限拒绝、服务失败、无匹配页面。家庭底部导航只用于 home、records、account；其余页面返回相应父页面。浏览器历史与 URL 页面标识保持同步。页面说明弹层支持键盘关闭及焦点返回。

## 实施接收条件

每个路由需接入当前权限、真实字段版本、来源与服务状态。页面存在不代表后端能力、岗位授权、临床验证、外部发送或生产可用。正式接口、临床配置和真实设备结果继续按 PRD 2.0 与既有 T 任务管理。
