# 甲方需求覆盖评估

日期：2026-09-28。依据为项目根目录《sJIA合并MAS预警平台需求输入.md》F01—F12、第5节数据流程、第6节页面验收与用户最新设计要求。对象为 ui-delivery 设计预览。页面存在、图稿导出和交互演示不代表业务验收通过。

## 当前设计

首页正文分为预警、儿童与三项症状、快捷记录三组。预警外层直接显示具体症状、最近体温与时间、就医行动；完整依据、来源与版本追溯位于详情。首页标题为“陪伴安安，健康成长”。设计性质与文案审批状态记录在画稿外的评审区和交付文档。

儿童形象提供发热、皮疹、关节炎三项示意、身体分类标记及详情入口。发热保留体温原值；皮疹保留观察结果；关节炎区域明确显示“关节不适待核对”和“关节炎尚未确认”。示意部位不代表真实受累位置。症状登记分别保留观察结果、发生时间及部位输入，家庭自报与专业核对分别表达。

预警文案属于待临床确认的设计内容。橙色情景说明发热、皮疹和关节不适，直接提示联系医生评估就诊安排；红色情景为呼吸困难、难以唤醒时的急诊行动说明，未关联为安安已发生的症状。颜色不由设计数值计算，不输出 MAS 概率或诊断。

## 需要继续完成的设计

1. **检验字典与动态变化**：F03—F05 需要医院检验字典、逐项时间与方法、多指标趋势交互。已有原图及手工登记保留原值、单位和报告时间；缺项保持未知，不能补成正常值。
2. **就医联系与摘要行为**：F09 需要正式联系资料、可用渠道和摘要输出方式。联系人缺失时显示准确原因，同时保留摘要准备入口。
3. **临床发布与验收条件**：F06—F08、F12 需要确认人、规则版本、适用前提、家庭文案和获准病例。仅有颜色及状态转换不足以满足临床验收。
4. **历史资料与边界情景**：补齐多时间点的真实选择、不同报告的可比性、跨患儿切换、关联撤销与记录更正后的提示更新验证。

## 医学表述与来源

家长可以记录关节痛、肿胀、活动受限等观察；“活动性关节炎”作为 MS 变量需要临床资料核对。身体标记用于三类症状导航，旁边明确注明概念示意。不得通过图片颜色或身体标记自动判定病情。

就医字段区分需要联系医生、出现指定急症表现时立即急诊、当前无法判断紧迫性、无新增安排。无当前预警不等于无需就医。未启用规则时不能发布自动临床结论；出现明确急症表现时不能要求用户等待平台回复。

文案校阅参考 [NIAMS 儿童关节炎说明](https://www.niams.nih.gov/health-topics/juvenile-arthritis)的关节表现与就诊说明，以及 [NHS 儿童发热说明](https://www.nhs.uk/symptoms/fever-in-children/)的呼吸困难、难以唤醒等急症表现。两者不替代本项目临床负责人的批准；未使用英国联系电话作为本地联系渠道。
