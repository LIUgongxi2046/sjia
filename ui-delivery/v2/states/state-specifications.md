# UI 2.0 状态说明

本目录提供 39 个页面与 328 个页面／状态组合。分母由 src/catalog.js 中 screens 和 statesFor 生成，逐页映射见 screen-design-map.csv。状态组件可以在桌面预览右侧切换；状态切换仅改变画稿，不调用业务服务。

| 状态 | 表达与操作 | 限制 |
| --- | --- | --- |
| default | 当前页面完整结构，缺少资料明确显示未知 | 不填入虚构病例 |
| loading | 加载反馈及准确说明 | 不同时显示有权读取前的病例内容 |
| empty | 暂无符合条件资料，提供相关入口 | 空内容不代表没有风险 |
| error | 读取失败与相关资料入口 | 不改写为没有资料 |
| offline | 当前网络中断，未保存输入仅在页面内 | 不宣称已保存或自动提交 |
| permission | 关联或岗位权限需要核验 | 状态画稿不显示受限内容 |
| partial | 项目、数值、单位、时间或来源需要补充 | 未知不补零或正常值 |
| stale | 原依据已有更新，需要重新生成 | 不恢复过期结果 |
| pending | 提交结果待确认，应查询原请求 | 不重复创建逻辑提交 |
| success | 保存完成的视觉组件与后续详情入口 | 只作为状态画稿，未创建真实保存记录 |
| attention／warning／urgent | 琥珀、橙色、红色，同时提供标题、图标与依据位置 | 不定义临床阈值，不提供未批准诊疗建议 |

访问受限、服务不可用和页面不存在已经是完整异常页面，状态分母仅包含其默认结构。提交待确认和完成反馈仅分配给相关表单；三级提示仅分配给首页、预警记录和提示详情。非适用状态不进入分母。

其他交互状态：输入控件的默认、焦点、编辑与只读语义，按钮的按下、禁用与主要／次要层级，筛选选中，文件选择与移除，详情展开，页面说明弹层，设计操作反馈弹层，提醒开关与暂停／关闭。返回、Escape 和焦点管理按实际浏览器操作检查。

临床已启用、批次有真实处理结果、核对完成、通知已送达等数据密集内容等待获准实际资料；当前仅交付结构与准确状态文字。没有实际业务结果时，不以状态组件检查替代相应业务验收。
