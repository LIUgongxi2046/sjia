# Logo 与儿童形象系列

## 品牌图形

品牌名称为 sJIA 守护者联盟。两侧人物围绕中央儿童形成环抱轮廓，表达家庭陪伴与共同守护。蓝色承接现有界面主题，青绿色作为辅助品牌颜色。产品全称通过界面文字排版，与图形独立维护。

Logo 使用透明 PNG，保留原始 Master，并从同一文件导出多个尺寸。横向组合使用图形与完整产品名称；狭窄位置使用独立图形。图形最小显示尺寸为 32 CSS px，四周保留图形宽度四分之一的空间。深色背景下使用带有白色底面的图标容器，保持轮廓清晰。当前交付为位图设计，不包含矢量源文件。

## 儿童形象

当前系列覆盖 6–12 个月和 1–3 岁两个年龄段，男童与女童两类，以及春夏秋冬四季，共 16 套正面形象。年龄范围依据本项目的婴幼儿交互方向确定，可通过 catalog.json 查看分类。婴儿使用坐姿，幼儿使用站姿，各年龄独立制作身体比例。

同一角色的四季版本继承同一春季 Master 的面部、发型、姿态、光线与构图，改变衣物。春季采用青绿色针织，夏季采用浅蓝棉质短袖，秋季采用燕麦色和焦糖色，冬季采用灰蓝保暖衣物。同季节采用相同色彩体系，性别分类不决定服装颜色。

角色为通用设计素材。年龄、性别及季节分类用于组织形象选择，不表示儿童当前体温、病情、发育评估或穿衣建议。初次使用可由监护人选择；资料可用时提出相应选项，继续保留人工选择。季节需要结合地区和家庭选择，不能仅按月份强制切换。现有通用形象继续适用于资料未配置的情况。

## 交付目录

- master：Logo 及 16 套儿童形象源图片。
- 1x、2x：从各自 Master 导出的透明 PNG，儿童目标槽位为 240 × 320、480 × 640，保持图像比例。
- index.html、gallery.js、gallery.css：可筛选形象的独立设计预览，包含 Logo 使用效果和首页素材预览。
- previews：品牌展示及儿童系列预览板。
- asset-manifest.csv：实际文件、尺寸、透明度及来源。
- generation-records.json：每次生成的提示词、参考图片和输出位置。
- checks：图片、导出与预览检查结果。
- brand-and-characters.pdf：六页品牌与形象手册，包含 Logo、四季形象和使用规则。

本系列交付正面图像。现有儿童正背视角素材仍保留在上级 assets 目录；新系列未创建对应背面或连续旋转模型。预览页面仅展示设计选择，不修改业务资料。
