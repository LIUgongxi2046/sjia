## 本轮额外发现并修复的工程问题

- 已发布的预设提示需要实时复核选择者授权，不能只靠历史选择和任务快照；同时修复自动触发 DTO 泄出内部预设绑定对象的问题。
- 同时读取家庭提示不应把 shared gate 升级为独占锁。读取辅助链已区分无写锁模式；关系撤销的原授权检查与动作放在一个事务中。
- 家庭首页必须保留历史字段质量原因的 `recorded/not_recorded` 状态。未知值和未知医学时间保持原样，严格的新临床字段契约不变。
- 支持端密码清理及卸载后旧登录结果处理，手工报告核对文案、时间/时区显示和局部权限拒绝重试均有对应工程回归。视觉和实际浏览器结果单列，不以 DOM 测试冒充截图验收。
- 档案变化摘要明确绑定批准运行配置的执行/租约/并发预算，失败时原子回滚；读取锁顺序及当前结果重验有真实独立连接回归。终止失败的原页可人工补充文书分类/文字并形成版本，保持原OCR失败、原件来源及无伪造候选边界；归组检查全部源页，不能借“未分配”绕过正在重试的状态限制。档案定向组合65/65通过，见 `ARCHIVE-DELTA-RUNTIME-BUDGET.md` 与 `FAILED-ARCHIVE-MANUAL-CORRECTION.md`。
- 记录当前/历史直链在全部字段不可见时拒绝返回医院、更正说明、报告时间/编号和附件等元数据；版本目录逐版本过滤，不以可见旧字段授权不可见的新版本。修复前HTTP重现保留，修复后新增及既有访问/真实事务组合42/42通过，见 `RECORD-METADATA-FIELD-SCOPE.md`。
