# 页面 UI 规格

能力：DESIGN，版本 UI 3.0。页面分母为 PrototypePage.tsx 中的23个入口，对应高保真图稿位于 screens/png。主画板采用登录后产品样式，设计性质与示例资料说明保留在外部评审区域及交付文档。全局三维图标、表面材质、尺寸与颜色引用 design-system.md 和 tokens.json。访问受限、服务异常与不存在页面保留其各自的异常原因和恢复入口。

底部导航仅在 S03 首页、S07 记录、S13-A 我的显示。其余20个页面及独立状态画面不显示底部导航。二级页面顶部返回优先返回当前来源，直接打开时依 navigation.js 返回父页面；更深详情保留对应记录标识。

## S01 登录身份

路由 /login。对应 FR-01、FR-09。页面上部显示现有 Logo 与“sJIA 守护者联盟”名称的横向品牌组合；当前画板展示登录完成状态，包括本人账号、监护关系、当前患儿、关联有效性与可访问范围，提供进入首页及管理患儿关联入口。正式认证方式仍由 D02 确定。

认证进行中禁用重复操作；失败原位说明；会话失效清除资料后显示重新认证入口。成功返回获准站内目标，受限目标进入访问状态页面。键盘焦点进入页面标题，错误关联实际认证字段。适用 ST01、ST05、ST16。

## S02-A 患儿关联

路由 /associations。对应 FR-01、FR-09。标题“患儿管理”，列表中每项显示获准标识、关联状态及本人权限摘要。不同状态使用文字，不用角色表情表达。页面主要操作为“申请关联”，说明放在列表之后。未登录时只显示访问条件，不展示空患儿列表或零人计数。

成功读取没有关联时显示“尚无可访问的患儿记录”。申请待核验、未通过、有效、撤销和失效分别标记。点击条目进入本人关联详情；有效关联的患儿切换入口仍位于首页。适用 ST01—ST05、ST16。

## S02-B 关联申请

路由 /associations/new。对应 FR-01、FR-09。单页呈现申请所需的实际字段，已知病情与核验说明使用 Disclosure。证明种类及认证流程未确认时不收集证明，不预设身份凭证。页面不展示与本申请无关的患儿角色。

只有真实配置及权限成立才开放“提交申请”。处理中限制重复提交，明确失败保留已允许的输入，未知提交结果进入查询状态。真实成功后显示申请状态及服务确认时间，不能直接显示病例访问成功。适用 ST06—ST14、ST16。

## S02-C 关联详情

路由 /associations/:relationId。对应 FR-01、FR-09。标题下依次为关联状态卡片、获准关联信息、本人权限列表、核验时间及说明。读取、登记、更正及提示接收分别展示，不合并为单个“已授权”。证明材料不作为普通家庭字段暴露。

待核验时只显示本人申请内容；撤销或失效后说明当前访问状态，提供返回管理页面。资源未读取时不显示虚构患儿或核验时间。适用 ST01、ST03、ST05、ST16。

## S03 首页

路由 /home。对应 FR-01、FR-02、FR-06、FR-07、FR-12。完整母版见 design-system.md 第2节。正文包含预警、儿童与三项症状、快捷记录三组；390 × 844 CSS px标准画框内完整显示三组内容与底部导航。预警显示具体原因、就医行动、最近体温和时间；健康档案承接四类完整资料入口。底部记录导航访问时间轴，报告页面展示检验完整性。

未登录只显示访问条件；角色作为通用图形时必须标明用途，不形成患儿身份。切换患儿重新获取当前权限及资料，旧响应不能更新新患儿。有效预警及必要操作完整呈现；长内容允许角色区域向后排列。适用 ST01—ST05、ST16—ST18、TW01—TW08。

## S04 体温与症状

路由 /register/observations。对应 FR-02。标题“体温与症状”，标题下持续展示当前患儿与语音输入卡片。语音支持普通话，单次最多60秒；开始、连接、聆听、结束与核对保持可见。文字输入可独立使用，未取得的语音内容保持空白。主要表单保留原始体温、原单位、测量时间、测量方式、三项观察和说明。

语音转写可以逐字编辑，确认后追加至其他表现与补充说明。需要重点核对数字、时间与否定表达；体温及症状字段由本人填写。语音未结束或文字尚未确认时禁用保存；取消本次保留此前文字。离开页面前需处理未确认内容，离开后终止语音采集。权限、音频设备、无语音、服务连接和语言错误原位说明。当前接入浏览器语音能力，正式症状保存仍属于业务服务范围。

体温采用大号数值输入与相邻单位控件，不使用默认正常温度或预选未知单位。症状状态明确提供观察到、未观察到、无法确定。具体项目来自获准字典。底部单一“保存记录”操作旁持续显示实际保存状态。家庭观察不会使儿童身体自动出现颜色标记。适用 ST06—ST14、ST16。

## S05 检验报告

路由 /register/reports。对应 FR-02 及甲方 F03、F04。页面默认展示原图资料列表与关注指标，提供异常指标和全部指标切换。拍照流程包含拍摄引导、系统相机或相册选择、照片整理、内容确认和保存结果。相机只在用户点击时打开，已有照片显示真实文件缩略图和顺序。

确认页面持续保留原图缩略图，点击全屏查看、放大、旋转和翻页。用户可依原图添加指标，填写原数值、比较符、单位、报告异常标记及参考范围。采样时间、出具时间和机构按需展开。没有填写的值保持未知；本人确认与专业核对分别记录。字段级 OCR 定位和检验方法字典尚未接入。

支持继续拍摄、相册多选、调整页序、确认移除及重新拍摄。图片变更或字段修改会取消本人确认勾选。文件错误保留已选图片；没有照片或没有确认不能保存。当前预览保存至本设备 IndexedDB，读取保存结果后展示成功，并可进入记录详情。服务器上传与 OCR 的业务状态仍需正式服务联调。

## S06 治疗资料

路由 /register/therapies。对应 FR-02。治疗清单、处方及药品照片使用与报告一致的原图流程，列表和详情均支持缩略图查看。确认页面优先显示原药名或治疗名称及实际使用状态，使用时间、出处及补充说明按需展开。实际使用状态初始为无法确定，同时提供持续使用、已结束、尚未使用。照片来自用户实际选择，名称和使用信息由用户填写。

使用时间允许未填写，已填写的结束时间不能早于开始时间。结束时间为空不推断持续使用。底部操作为“保存原图与记录”，需要用户核对患儿归属；设备存储失败保留当前输入。日期精度、专业治疗分类及服务器核对流程继续依赖正式业务规则。

## S07 记录

路由 /records。对应 FR-03、FR-08、FR-11。标题“记录”，上方两项工具入口为就医摘要和我的草稿。随后显示类别 SegmentedControl、筛选按钮及筛选摘要，正文为时间轴。时间轴卡片同时呈现原值、单位、真实事件时间、来源及核对状态。

筛选面板保留项目名称、来源、核对状态和日期范围，提供“清除筛选”。筛选无结果与全部无记录使用不同说明。时间未知条目独立列于“时间待补充”，迟到报告显示其真实采样时间及新近登记说明。返回时恢复筛选和浏览位置。适用 ST01—ST05、ST16。

## S08 记录详情

路由 /records/:recordId。对应 FR-02、FR-03、FR-08、FR-12。标题区域包含记录类别及获准患儿标识。内容分组为原始内容、来源与状态、时间与版本；采用 SegmentedControl，窄屏和大字号允许多行。当前记录版本优先呈现。

新增本地原图记录通过独立记录标识打开，刷新后重新读取对应文件。报告详情保留关注与全部指标，治疗详情保留名称与实际使用状态；两类详情均有原图查看入口。没有提供的时间、来源及名称明确标为未填写。

来源、格式质量、核对状态分别展示。原文入口紧邻对应字段，未知字段有明确文字。更正、历史、历次结果仅在实际对象及权限成立时开放。儿童面板进入本页后返回原面板类别及时间。适用 ST01、ST04、ST05、ST14、ST16。

## S09 历次检验

路由 /records/analytes/:analyteId。对应 FR-03。上方显示原项目名称及比较条件，正文先提供原值列表，存在可比较资料时增加趋势图。每个点触控后显示原值、限定符、单位、采样时间、来源和核对状态；完整列表始终可访问。

少于两次可比较结果显示资料不足。同时间冲突、单位未知、方法不一致和时间未知分别说明。限定值不画为精确点，缺失区间不连线。没有获准数据时只呈现当前访问或读取状态，不生成波形。适用 ST01、ST02、ST04、ST05、ST16、TW05。

## S10-A 更正记录

路由 /records/:recordId/correct。对应 FR-08、FR-09、FR-12。当前原记录类型决定字段，不要求用户重新选择类型。标题下显示当前版本和患儿，允许修改的字段随后排列，更正原因明确必填。专业字段仅提供获准的更正请求入口。

底部操作为“保存更正”，原记录、版本及影响说明按需展开。提交后新版本显示实际核对状态，相关摘要的有效性按真实服务结果更新。版本冲突时保留当前输入并要求重新读取，不能自动合并。适用 ST06—ST14、ST16。

## S10-B 更正历史

路由 /records/:recordId/history。对应 FR-08、FR-09、FR-12。按获准时间排列只读版本卡片，记录版本、原因、操作者可见标识、修改时间及核对变化。版本内容由展开区域呈现，当前版本有文字标记。

不提供恢复旧版本按钮。历史读取仍检查当前权限及可见字段。无获准历史时说明原因，不能创建版本条目。返回当前记录保持来源上下文。适用 ST01、ST02、ST05、ST16。

## S11-A 预警

路由 /alerts。对应 FR-06、FR-07、FR-12。从首页预警进入。当前获准结果位于顶部，必要操作在结果下方，历史提示只有当前策略允许才展示。服务状态和资料依据放入可展开区域。

未启用显示“临床提示功能尚未启用”。已启用但无事件必须使用实际服务状态和批准文字，不推断健康。有效事件卡片显示批准标题、时间、有效性及本人查看状态。正文没有角色动画或综合健康分。适用 ST01、ST05、ST16—ST18。

## S11-B 预警详情

路由 /alerts/:alertId。对应 FR-07、FR-12。结果及批准操作居前，随后是评估时间、依据记录、来源、核对及当前有效性，技术版本按需展开。只有有效批准的联系资料才显示联系操作。

真实进入页面后更新本人查看时间，预加载不计查看。事件失效停止将内容作为当前提示展示；联系方式失效停止联系入口。点击联系不会显示已经就医或已经完成诊疗。适用 ST01、ST05、ST16—ST18。

## S12-A 就医摘要

路由 /summaries。对应 FR-11、FR-12。从记录页面进入。患儿、时间范围与单一“生成摘要”按钮位于上部；内容目录、生成规则和就诊查看说明按需展开。日期为空不预填病例范围，结束日期早于开始日期原位报错。

没有可见记录时明确范围内无可汇总资料。生成中保留范围且限制重复操作；失败保留选择。真实成功进入平台内摘要，不自动提供公开分享、文件导出或发送。适用 ST01、ST02、ST05、ST06、ST11、ST15、ST16。

## S12-B 摘要详情

路由 /summaries/:summaryId。对应 FR-11、FR-12。采用阅读页面，前部显示患儿标识、资料范围、生成时间和有效性。正文按体温症状、检验资料、治疗资料及资料不足分类，原始数值、单位、时间、来源和核对状态在同组内。

每条获准依据可返回原记录。新增、更正或核对撤销后使用明确“需要重新生成”提示，旧内容不能呈现为当前版本。联系方式仅在获准且有效时显示。当前无业务导出功能；本次设计规范 PDF 与患儿摘要导出分属不同产物。适用 ST01、ST04、ST05、ST15、ST16、ST18。

## S13-A 我的

路由 /account。对应 FR-01、FR-09。单一账号区域位于顶部，下方两组入口为患儿管理和资料使用说明。管理内容之后、退出操作之前放置现有 Logo 与“sJIA 守护者联盟”名称。未登录在账号区域提供一次登录，已登录才显示退出操作。账号头像使用三维 UserRound 图标，不用儿童形象表示监护人。

页面不显示患儿资料统计、奖励、健康排名或额外功能。退出按真实会话结果清除受限内容，账号切换不会保留上一账号资料。适用 ST01、ST05、ST16。

## S13-B 资料使用说明

路由 /account/data-use。对应 FR-09。分组 Disclosure 为访问范围、资料来源与核对、草稿及退出、保存与删除、联系信息状态。正文 16 px、行高 24 px，长内容允许自然增长；标题保持明确。

未确认的保存期限、删除流程和联系信息不填示例内容。删除申请只能在批准流程存在时提供，申请与处理完成分别反馈。当前页面不收集病例，不需要患者加载或空病例状态；静态文档读取失败使用通用错误页。

## S14 我的草稿

路由 /drafts。对应 FR-02、FR-08、FR-09。从记录页面进入，标题“我的草稿”。顶部类别筛选，正文卡片显示本人获准草稿类型、患儿标识和服务确认时间。草稿与正式记录使用不同标题，不进入时间轴。

恢复前检查本人、关联、字段配置及原记录版本。面板提供继续编辑和放弃草稿；放弃前明确影响。已提交、过期、已放弃和版本冲突分别说明。无草稿只在成功读取后展示，未登录不显示零份。适用 ST01—ST05、ST09、ST14、ST16。

## S15-A 访问受限

路由 /access-denied。对应 FR-01、FR-09。使用 LockKeyhole 标准图标、标题“暂时无法访问”和服务允许的原因。根据真实状态提供重新登录或查看关联入口。没有患儿区域、残余照片或历史数值。返回操作只进入当前可访问地址。适用 ST16。

## S15-B 服务不可用

路由 /service-unavailable。对应全部依赖服务的家庭流程。使用标准状态图标、准确标题与可执行返回入口。真实请求失败且允许重试时提供“重新加载”；未接入的服务显示当前状态，不提供无实际请求的成功按钮。无虚构恢复时间。适用 ST05。

## S15-C 页面不存在

路由通配 *。显示“页面不存在”、地址状态及“返回首页”。不显示资料已删除、无权限等未经证实的原因。不携带患儿区域。资源不存在与路由不存在分别处理，病例资源状态由真实服务决定。

## S00 独立评审目录

路由 /prototype。沿用现有独立入口的评审用途，提供 23 个业务及状态页面的查看位置与能力说明。独立 UI 预览通过 index.html 呈现页面目录、状态画板和设计说明。此页面不计入家庭业务 23 页分母，不加入底部导航。

## 新增交互面板

TW-PANEL 从首页展开查看进入，完整规格见 design-system.md 第 2.3 节。体温、症状、检验、治疗四类面板沿用同一 BottomSheet 容器，各自展示获准资料、真实时间、来源与核对状态，提供查看记录及有权限时的登记入口。未取得资料时显示准确读取条件。

主面板打开子类别时在同一容器切换视图，提供返回主面板；不叠加多个对话框。筛选及历史时间保留在当前会话，关闭后清除需要重新授权的内容。完整状态见 TW01—TW08。
