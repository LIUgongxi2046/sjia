## 功能与持久结果

本人能够创建明确设置的记录任务，保存标题、说明、保留政策及版本；任务状态分别为 pending、completed、cancelled。任务具有独立实体和保存时间，明确完成或取消时保存结束时间。本人任务、草稿和报告批次分别按当前主体、患儿、关系及许可范围查询，目录不返回其他主体内容。

提醒创建默认关闭；本人能够明确启用、暂停、关闭、延后，并同时保存时间、IANA 时区和安静时段。未来时间、版本、严格 boolean 和准确目标身份均在提交位置校验。计划计算覆盖跨午夜和夏令时，静默时段内停止新发送。目标完成或取消、撤权、来源版本变化及环境停用均由当前状态控制；终态不自动恢复。

设置写入使用持久 WriteIntent、WriteRequest 和 AuditEvent。原操作、路由、request_id、generation、正文摘要、当前授权及保存版本共同校验。重复提交返回原回执；未知结果保持 unknown。本人能够查询原请求、重新提交符合条件的原请求，明确取消未提交请求后更正输入。正文只保存在业务数据库和当前页面内存，浏览器持久存储不保存资料。

到期调度重新检查本人权限、目标状态、来源保留政策、当前运行配置、专属资料提醒政策、执行人员和病例读取许可。独立签名许可绑定准确通知、任务、设置版本、计划时间和正文；Task 与 MaterialReminderNotice、Outbox 和审计同事务保存。资料提醒与临床提示分别使用独立实体，当前 Native Provider 的并发和每日消息预算共同核算。

站内通知先保存 accepted 和签名受理回执。本人主动打开正文后，前端在页面可见且正文进入显示区域时提交短期凭证；服务端重新检查当前设置、授权和原正文，保存 delivered 及签名证明。阅读时间随后保存，重复确认和阅读保持原时间。关闭、暂停或任务终态取消尚未发送的旧计划；已有受理、送达和阅读事实持续保留。失败重试沿用原 Provider request 身份，未知状态要求核验原结果。
