## 决策与约束

- `verify_fields` 建立 verification + verification_field，并更新 field_verification_state（verified/needs_correction）；只更新传入字段。
- `revoke_verification` 撤销证明并置状态 revoked，patient.verification_epoch + 1。
- 新记录版本的新字段不继承旧证明（新 field_id 无状态）。
