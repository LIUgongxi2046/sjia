# 原 UI 四项缺口补齐记录（2026-10-11）

模式：IMPLEMENT。范围是 UI-G01–G04 及同源字段时间排序问题。此记录不替代最终完整回归、真实账号正向流程或同状态视觉验收。

## 已实现

### UI-G01：已有症状进入准确记录

首页体温、皮疹和关节观察保留患儿、记录、不可变记录版本、字段引用。点击身体标记和对应状态卡进入准确字段的记录详情；快捷登记独立保留。无记录或医学时间无法确定先后时，进入相应获准档案分类，不把查看操作当成新增登记。

当前详情继续使用 `read_raw` 权限。URL 携带所选版本/字段，读取后验证一致性；更正后版本变化、字段不可读或撤权时不会替换为其他值。只有服务端允许 `read_history` 才显示所选旧版本入口。

服务端查询的排序候选限定到实际匹配且获准的字段，完整记录投影仍保持原字段权限。精度排序保留秒内差异。签名游标绑定新的排序版本，旧排序的游标明确返回 `CURSOR_STALE`。

前端的线性复杂度选择器比较医学时间范围，不使用记录保存时间或同记录的其他症状时间决定某项“最近记录”。原始值、单位、时区及精度不改写；未知、歧义、范围重叠和同时间多条值保留候选，不能自动判定临床状态。

### UI-G02：真实示意形象选择链路

健康档案内提供“选择形象”，包含通用回退及原 16 套素材；预选、取消、应用、重选均接入生产组件。应用同步更新当前首页及档案形象。

这是所有患儿页面共用的“当前浏览器外观”。仅保存经过白名单核验的素材 ID；不保存患儿、账号、年龄、性别或健康信息，不修改任何临床资料，不跨设备同步。没有自动季节变化或临床属性推断。浏览器拒绝保存时仍可使用当前选择并显示准确提示。素材加载失败保留文字入口和重试。取消、Escape 不保存。

### UI-G03：展开档案原结构

实际查看 TW-PANEL 原 PNG 后补齐大幅居中儿童、身体示意入口、两侧四类摘要、症状三联图及三项记录摘要、时间选择与形象入口。分类和登记功能继续保留；摘要仅使用权限校验通过的实际资料。

份数按当前可读记录去重，不按字段数重复计数。症状摘要按各字段自身医学时间选择；选定时间、未知时间、读取中、失败和无记录明确区分。失败和分页未完成不会显示部分汇总或虚假的零值。档案详情链接固定版本/字段；患者、权限范围切换及晚到响应受到隔离。

### UI-G04：实际 ShadowRoot 深色主题

正式 UI2 框架内新增原设计深色语义颜色及立体材质，覆盖家庭、表单、支持页与实际弹层。提供跟随系统／浅色／深色，订阅系统变化；只保存合法外观字符串。保持高对比度、系统强制色和减少动态偏好，弹层上限 88dvh、焦点循环及关闭后恢复。

## 独立 DEV 外观样本

为了在不访问私有业务数据的情况下检查新增界面，将 ArchivePanel 提取为实际生产共用的纯资料展示层；HealthArchive 的授权读取、分页、范围与晚到响应处理仍留在生产包装组件中。

`/dev-specimen.html` 展示首页，`/dev-specimen.html?panel=1` 展示展开档案；可经 `/dev-preview.html?path=%2Fdev-specimen.html%3Fpanel%3D1&viewport=390` 使用真实 390 × 844 CSS px iframe。入口仅在 DEV 启用，不由正式 App 路由或生产入口引用。

样本使用明确编造的固定展示数据、MemoryRouter 和实际共享组件。始终显示“合成界面样本，非真实业务结果”；没有 AccessProvider、会话注入、私有 API 或业务提交。`check-design-specimen-dom.mjs` 禁止导入授权/私有接口模块，并确认所有交互零 fetch。此样本可提供布局证据，不能作为真实登录、获准数据、记录保存或临床批准的证据。真实浏览器截图结论另行记录。

## 真实渲染对比后的尺寸修正

根据独立 390 × 844 渲染与 TW-PANEL 对比，恢复“孩子的记录”静态标题、原稿字号、姓名首字圆形头像、44px 立体圆形关闭按钮和 20px 水平内边距。档案原生滚动保留，但滚动条不再吞掉内容宽度；参考目标是 348px 内宽、250px 儿童区、120px 症状图和至少 102px 症状摘要卡。以上是源码目标，不是已通过的实测结论。

主卡保留原值、单位和完整核对状态；完整时间、来源、原值与固定版本入口在时间控件之后的“记录时间、来源与核对”展开区中可读。长值允许增高，不作省略截断；窄屏和字体放大时摘要、症状与形象选项重排。当前浏览器共用的示意形象范围持续显示，选择展开后先展示完整范围及安全说明，再允许应用。

430px 首页患者说明与箭头分离布局，避免箭头独占一行；390px 首页主结构未重构。补回原深色主卡底部浅色混合材质。合成样本标记移到预览容器外层持续可见区域，不在档案真实内容中重复占位；直接打开样本仍有独立粘性标记。浏览器复测必须重新加载预览包装页，避免旧 HTML iframe 标志残留。

修正仅调整展示与 DEV 样本，HealthArchive 授权读取包装不变；本轮未改后端、统计区间或内容处置引擎。真实数据与授权正向流程、完整集成回归、修正后的像素复测分别保留待验证状态。

独立第二轮验证确认内容内宽与关闭按钮已恢复，并发现四摘要 24px 图标使网格多出 10px。后续修正将其恢复为原稿 19px，保留自然增高行；档案症状图依据最终覆盖规则使用全宽 120px 高、摘要上边距 -5px，首页图未改。档案单独补回 3px 背景模糊，并让数字徽章随放大文字增长。上述后续源码仍待独立同源实测。

暗色首页材质补充：原稿 signed-in 的首页 masthead 使用 static 定位，46% 高度柔光以整设备为参照。生产仅对暗色首页恢复该定位，页面几何及其他页的帮助按钮定位不变；强对比和强制色关闭装饰层。首页儿童区域不是档案 twin-stage，恢复原稿独立的较亮光晕，不再复用档案暗光晕。独立浏览器已确认此前档案关键几何和 200% 数字徽章，本次暗色材质仍按新清单单独复测。

材质最终层叠修正：独立 computed style 确认先前主卡混色规则被包含双 class 分支的 :is() 通用规则压过。本次使用同权重且后出现的首页限定选择器，恢复 light/dark 两种主卡材质；两种首页均恢复原定位柔光。新增 CSS AST 级 specificity/cascade 回归，修正前能真实选出错误 153deg 背景并失败，修正后要求正确 155deg 混色赢出且高对比 !important 仍优先。档案浅色编号恢复原棕色，深色保持高可读；摘要与症状卡边界和 tile-shadow 恢复原材质，尺寸和业务值未变。

深色首页局部可读性：独立复测发现恢复柔光后 11px 档案链接原蓝色相对附近实际背景不足 4.5:1，固定 PNG 箭头也偏暗。仅该入口文字采用 #83baff，患者箭头与档案入口两处 utility 3D 素材用局部亮度滤镜，保持 14px 尺寸与原素材，不影响医学插画或浅色模式。高对比文字继续使用语义前景，强制色恢复系统文字并取消滤镜。新增层叠与作用范围回归；最终图标实拍与文字复测另由独立浏览器记录。
