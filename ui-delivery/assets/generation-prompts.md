# 儿童角色生成记录

生成方式：内置 image_gen__imagegen。角色作为设计素材使用，不包含病例、身份或临床结果。正面为全新生成，背面以正面 Master 为输入。图像均为 1086 × 1448 RGBA PNG，透明通道取值包含 0 与 255。

## 正面提示词

用途：儿童健康记录手机 H5 的高保真 UI 角色素材。生成一张通用幼儿的完整全身三维插画，透明背景，单个角色正面站立，头部与双脚完整，角色居中，周围保留约百分之八透明空间。角色为东亚幼儿外观，短黑发，自然儿童身体比例，温和平静的中性表情，小巧五官，双臂自然略微离开身体，双手可见。穿浅蓝色长袖上衣、米白色长裤和白色鞋袜，衣物完整。采用精致的三维产品插画材质，自然柔和正面光，清晰轮廓，衣物有轻微织物质感，肤色自然。色彩适合白色与极浅蓝 iOS 界面。不要文字、数字、标识、背景、地台、阴影底板、额外物体、医疗器械、皮疹、病情特征或身体标记。角色只承担通用视觉资产用途，不表示真实患儿或健康状态。竖向构图，建议 3:4 比例。

## 背面提示词

为提供的通用儿童角色生成背面视图，只改变观察方向为正后方。保留同一角色的发型、年龄比例、浅蓝长袖上衣、米白长裤、白色鞋子、站立姿态、双臂位置、光线、材质、图像比例与角色在画面中的大小。头部、双手与双脚完整，透明背景，单个全身角色，不增加任何文字、数字、标记、道具或背景。此图用于手机 UI 的正面与背面视角切换。

## 尺寸导出

scripts/export_assets.py 使用 Pillow 按明确的切图要求从各视角 Master 导出 240 × 320 与 480 × 640。导出保留比例与 RGBA，不重新生成角色。全新生成条目的 source_image_path 指向保存后的源 Master，用于清单校验；该次生成没有输入参考图片。
