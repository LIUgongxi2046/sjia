## 实现与约束

VoiceEntry通过MediaRecorder与同源音频接口取得真实文字。speech.py使用PyAV与本地faster-whisper，音频只在内存处理，鉴权与患儿范围在推理前后检查。模型目录通过配置注入，依赖版本已锁定。输入、容量、取消、超时和重试保持明确状态。

PhotoReview直接显示SourceGallery缩略图。UploadedPhotos逐页显示识别状态，保留失败照片和已有候选，重新识别只替换对应页。ReportsPage保留全部字段与来源。TherapiesPage使用真实Ark提取候选药名和原文，采用后保留source_file_id/source_text，本人另行确认实际使用情况。

共享表单样式及首页比例按UI3依据和本次反馈调整；没有缩减字段或生成临床结论。T13、T14、T15、PRD、HLD、前后端LLD及运行说明已同步。
