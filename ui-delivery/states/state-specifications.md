# 页面状态与交互规格

能力：DESIGN，版本 UI 3.0。以下状态在业务应用中由真实身份、真实请求及获准记录驱动。对应画板使用明确标注的设计内容，不将界面文字作为业务运行证据。组件状态共 32 项，其中通用 18 项、照片 6 项、儿童资料交互 8 项。预警另有 10 种画面，详见 alerts/specifications.md。状态画板使用与主页面相同的三维图标和容器材质，在反馈区域之外保留当前任务内容，检查长文字与已填字段的共同布局。

## 通用状态

| ID | 进入条件 | 布局及准确反馈 | 操作与结束条件 |
| --- | --- | --- | --- |
| ST01 | 正在进行真实读取 | 当前请求区域显示“正在读取”，结构无数值；导航保留 | 实际结果进入内容、空数据或失败；权限失效清除资料 |
| ST02 | 请求成功，授权范围内为空 | 类别图标、准确空态及必要入口；不使用健康结论 | 有登记权限时提供登记；无权限只解释当前范围 |
| ST03 | 真实筛选结果为空 | 筛选条件仍在，显示“没有符合条件的记录” | 清除筛选后重新读取，不清除全部记录 |
| ST04 | 获准内容部分缺失 | 原值照常呈现，缺少来源、单位、时间等逐项注明 | 对具体记录按权限补充；未知不能变为零 |
| ST05 | 请求失败或服务不可用 | 错误出现在请求区域，显示“暂时无法读取”；保留允许的操作 | 用户主动重新请求并重新鉴权；未接入服务只能查看说明 |
| ST06 | 当前输入不符合已确认格式 | 字段旁显示原因，顶部错误列表，焦点进入首个错误 | 用户修改对应字段后重新校验；不静默截断 |
| ST07 | 编辑存在未确认保存内容 | 保存操作附近持续显示“尚未保存” | 离开时进入确认面板；服务器确认前不显示保存时间 |
| ST08 | 服务端正在保存草稿 | 显示“正在保存草稿”；正式提交状态独立 | 串行确认版本及时间；失败保持输入并说明未保存 |
| ST09 | 取得当前账号有效草稿 | 展示真实保存时间及类型，提供继续编辑、放弃草稿 | 权限、字段配置和原版本检查通过后恢复；放弃前确认 |
| ST10 | 用户准备提交完整当前编辑 | 同页呈现患儿、原值、单位、时间、来源和需补内容 | 单一保存操作触发请求；更正原因必填，不增加无必要确认页面 |
| ST11 | 已发出正式保存或生成请求 | 按钮显示处理中，禁用重复触控，结果区域不显示完成 | 真实响应决定成功、明确失败或结果未知 |
| ST12 | 已发送但响应无法确认 | 显示“保存结果待确认”，保留原 request_id 对应状态 | 只提供查询；确认未提交才允许重试；未知期间不新建提交 |
| ST13 | 服务确认保存成功且返回记录 | 页面结果区显示实际记录与保存时间、来源和核对状态 | 进入真实记录详情并重新读取；保存不表示风险评估已完成 |
| ST14 | 版本与当前服务记录不一致 | 显示“记录已有更新”，保留获准输入和冲突字段 | 重新读取后由用户核对，再提交当前版本；不自动合并 |
| ST15 | 摘要依赖内容或权限已变化 | 顶部持续显示“资料已变化，需要重新生成” | 当前权限成立才允许生成；旧摘要不作为当前资料 |
| ST16 | 会话失效、关联撤销或无权限 | 清除全部受限文字、图片及面板内容；显示访问状态 | 重新认证或查看关联；只恢复同一账号的有效服务端草稿 |
| ST17 | 临床提示未启用 | 显示“临床提示功能尚未启用”或首页准确未评估文字 | 仅查看功能状态；无风险等级、临床事件及联系按钮 |
| ST18 | 提示或联系信息不再有效 | 停止展示受影响内容；明确当前有效性 | 重新读取当前获准内容；不使用过期联系入口 |

ST01 不采用循环假进度百分比。ST13 不使用角色欢呼表示病情变化。ST05、ST12 和 ST16 的错误具有不同含义，不能合并成暂无资料。

## 照片状态

| ID | 进入条件 | 界面表现 | 恢复及可追溯条件 |
| --- | --- | --- | --- |
| PH01 | 用户取消系统文件选择 | 返回原照片页，保留已确认内容 | 不显示上传成功或新页数，不发起 OCR |
| PH02 | 真实文件不满足获准类型或容量 | 对该文件明确指出原因，其他照片保持原状态 | 重新选择符合配置的文件；限制来源于实际配置 |
| PH03 | 真实上传正在进行或明确失败 | 各照片独立显示真实进度或失败状态 | 按当前权限重试；只有服务确认后才关联原件 |
| PH04 | OCR 部分成功或无法识别 | 已有原文保持可见，无法确认字段集中列出 | 用户查看原文并修订，保留原识别结果及来源位置 |
| PH05 | 替换或移除已有照片 | 显示具体照片及受影响内容的确认面板 | 取消不改变内容；替换完成使关联字段重新待确认 |
| PH06 | 相机权限拒绝或照片无法读取 | 对当前操作说明原因，提供相册或重新选择入口 | 只有真实文件服务及权限可用时执行，不制造替代照片 |

## 儿童资料交互状态

| ID | 进入条件 | 角色与资料表达 | 操作及结束条件 |
| --- | --- | --- | --- |
| TW01 | 尚未登录或未选择有效患儿 | 无患儿身份及数值，通用形象注明用途 | 进入登录或关联；不得通过角色触控读取病例 |
| TW02 | 读取成功且存在获准资料 | 中性形象，四类标签分别显示真实资料状态 | 点击标签进入相应面板，再查看记录来源 |
| TW03 | 已展开某类别 | 面板标题、获准患儿、真实时间、来源和内容明确 | 返回保持类别及时间；关闭恢复入口焦点 |
| TW04 | 用户选择真实历史时间点 | 标题“查看当时记录”，每类内容附自身事件时间 | 仅按批准的历史选值语义读取；切回最新重新查询 |
| TW05 | 时间未知或数据不可比较 | 资料进入时间待补充或不可比较区域；不连线 | 查看原记录并按权限补充，不猜测状态变化 |
| TW06 | 角色素材加载失败 | 显示“形象暂时无法显示”，资料文字入口完整保留 | 提供重新加载；图像恢复不能改变资料值与状态 |
| TW07 | 切换患儿、撤销关联或内容策略变化 | 立即清除角色关联标识、标签资料和历史选择 | 新请求通过权限检查后呈现；旧响应不能写入当前视图 |
| TW08 | 窄屏、大字号、减少动态或键盘打开 | 标签转为流式列表，非必要动画取消，面板纵向滚动 | 所有入口可通过触控及键盘访问，内容不被固定区遮挡 |

## 确认与反馈组件

离开编辑的面板明确当前内容尚未保存，提供继续编辑、保存草稿后离开、放弃编辑。只有保存服务确认后才能离开；保存失败继续停留。当前没有病例输入时不触发资料丢失警告。

移除照片、移除已有输入项目及放弃草稿分别呈现具体对象与影响，危险操作不默认聚焦。取消按钮和关闭按钮均可达，关闭恢复触发位置。提交成功、草稿保存及预警更新分别反馈；Toast 不作为唯一完成记录。

## 状态覆盖与验证要求

页面到状态的映射记录在 route-design-map.csv。每个状态的预期须在真实服务和授权资料下验证；状态切换器、随机数据及计时器不能作为业务证据。长文字、200% 字号、320/360/390/430/580 px、横屏、键盘及焦点路径属于全部页面的布局要求。

静态资料说明与页面不存在不适用病例空数据或病例成功状态；原因是它们不读取病例。受控核对、规则批准和发布不属于家庭页面，不通过增加家庭按钮覆盖。角色奖励、连续学习、游戏关卡不属于 PRD。
