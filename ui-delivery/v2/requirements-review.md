# PRD 2.0 与页面关联

依据项目根目录《sJIA合并MAS预警平台PRD.md》V2.0.0。关联表示设计入口与内容结构覆盖，不代表业务或临床验收通过。页面编号和路径以 screen-design-map.csv 为准。

| 需求 | 设计页面 | 主要表达 |
| --- | --- | --- |
| FR-01 账号与患儿关联 | 登录、患儿管理、申请关联、关联详情、访问受限 | 当前身份、资料归属、有效关系与拒绝访问 |
| FR-02 资料登记 | 体温与症状、拍照添加报告、治疗资料、逐项确认 | 原始内容、本人确认、未知与保存反馈 |
| FR-03 时间轴 | 记录、记录详情、历次检验 | 医学时间、来源与资料状态 |
| FR-04 分类条件 | 评估依据 | 受控内部计算依据，未知保持未知 |
| FR-05 MS 评分 | 评估依据 | 独立计算资格与依据，不向家庭呈现未批准结论 |
| FR-06 动态线索与提示 | 首页、预警记录、提示详情、评估依据、内容与启用 | 当前有效性、三级提示、依据和启用限制 |
| FR-07 接收记录 | 预警记录、提示详情、通知记录 | 受理、送达、查看分别呈现 |
| FR-08 更正与历史 | 更正记录、更正历史、历史版本、我的草稿 | 更正原因、版本、核对撤销与本人草稿 |
| FR-09 权限与资料使用 | 资料使用说明、访问受限、用途与副本 | 当前可见范围、用途与复核记录 |
| FR-10 专业核对 | 专业资料核对 | 字段、来源、版本与专业资格 |
| FR-11 就医沟通 | 准备就医摘要、就医摘要 | 资料范围、原值、时间、出处及缺项 |
| FR-12 内容批准 | 提示详情、内容与启用 | 批准内容、家庭可见范围、启用状态 |
| FR-13 逐项时间 | 拍照添加报告、逐项确认、原始资料、专业资料核对 | 每项事实独立时间、原文、语境和来源 |
| FR-14 长期档案与批量任务 | 长期档案、批次进度 | 逐页接收、识别、确认和归档进度 |
| FR-15 文书与就诊归组 | 文书与就诊归组、逐项确认、长期档案 | 医院、文书、多次就诊与未确定归属 |
| FR-16 重复资料关系 | 重复资料核对、专业资料核对 | 同一文件、同次采样、独立采样和更正关系 |
| FR-17 资料查找 | 长期档案 | 医院、文书、确认文本及就诊筛选 |
| FR-18 新增内容摘要 | 这次新增了什么 | 比较基准、逐条来源和内容有效性 |
| FR-19 观察时段 | 观察时段、历次检验、评估依据 | 真实时间范围、采样间隔与资料时效 |
| FR-20 独立评价集合 | 资料与评价集合 | 用途、患者划分、独立标签及真实分母 |
| FR-21 原件与用途副本 | 原始资料、资料使用说明、用途与副本 | 原始版本、处理用途与外发前复核 |
| FR-22 自愿提醒 | 资料补充提醒、我的、通知记录 | 默认关闭，自主设置、暂停、延后和关闭 |

专业资料核对、评估依据、内容与启用、资料与评价集合、用途与副本、通知记录共六个受控页面依据 PRD 推导，标记为 INFERRED。其路由用于设计评审；正式角色授权和临床内容批准继续由对应需求约束。

临床准确性、动态计算、AI 提取效果、通知回执、资料数量和真实保存需要正式业务证据。当前设计中没有获准病例，相关内容呈现未知、未提供、待选择或待确认。
