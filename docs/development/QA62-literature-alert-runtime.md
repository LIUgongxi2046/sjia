## 采用原则

AI 文献核查记录实际方法和依据，不登记不存在的专业人员、核对证明或临床答案。既有字段的核对状态保持实际状态，未达到计算资格的字段保留排除原因。研究与软件流程验证分别记录，缺少资料时不能给出确定的 MAS 结论。

规则、用途、时间窗口、输入政策及发布内容采用当前正式配置接口和资格检查，证据绑定准确版本与实际运行制品。每份配置的依据与验证范围需要明确，结构检查不得登记为临床准确性评价。当前测试账号及获准病例的最小执行范围随实际需要形成明确清单，不新增其他人员或病例范围。
