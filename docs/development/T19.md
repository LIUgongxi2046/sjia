## 检索与输入依据

读取依据：[PRD 第 8.14.3 节](../../sJIA合并MAS预警平台PRD.md)、[预警编排 LLD 第 3.2 节](../../sJIA合并MAS预警平台预警编排LLD.md)。

关键采用结论：

- 唯一公式 `MS = 2.44×CNS + 1.54×出血 − 1.30×活动性关节炎 − 0.003×血小板 + 0.001×LDH − 0.004×纤维蛋白原 + 0.0001×铁蛋白`。
- 七项均具备资格才计算；任意缺项不产生完整总分；专业变量未知不按 0 计算。
- Decimal 运算，展示舍入前比较 `MS ≥ −2.1`。
